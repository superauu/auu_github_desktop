# AuuGit v0.6.4 · 多平台自动更新与体验打磨

## macOS / Linux 自动更新

- **三平台接入自动更新**：发布时把 macOS（aarch64 / x86_64）与 Linux 的更新签名合并进更新清单 `latest.json`——两个平台此前只能手动下载安装，现在与应用内「检查更新」完整打通。
- **安装包体积下降**：Rust 侧启用 thin LTO + 符号裁剪，三平台产物体积预期缩减 20~40%。

## Pull Requests 视图重设计

- **100% 宽度铺满**：详情内容不再锁在窄列，右侧不再留白。
- **状态卡扩为四张**：审核状态、CI/CD 检查、代码改动统计之外新增作者卡（作者与创建日期）。
- **标签行**：以 GitHub 原色徽章展示 PR 标签（dependencies、javascript 等）。
- **机器人描述可读化**：Dependabot 等机器人写入的 HTML 描述不再显示原始标签，转为可读纯文本（安全提取，无脚本执行面）；评审弹窗与时间线评论同步接入。

## 性能

- **消除全树重渲染**：修正多处整店订阅——CI 轮询期间不再每 15 秒重渲染整棵组件树，拖拽分栏不再每帧全树渲染。
- **轮询开销下降**：每 10 秒的工作区状态轮询改结构化比较，大仓库不再产生高频字符串分配。
- **AI 生成提速**：生成提交说明前的文件 diff 采集由串行改并行。
- **网络与进程**：OAuth 轮询复用连接池（不再反复 TLS 握手）；git 命令超时按命令分档，高频只读命令挂死时 5 分钟内释放并发槽而不是占满 15 分钟。

## 正确性与安全

- 后端静态锁统一「中毒自动恢复」：任一持锁线程异常后，文件写入 / 仓库授权 / 外部工具配置不再永久报错直到重启。
- 强杀超时进程的 taskkill 改系统目录绝对路径解析，防工作目录同名程序劫持；默认传输白名单剔除无加密无认证的 `git://` 协议。
- 多平台托管：仓库快速切换不再出现「A 仓库的 PR / 流水线挂到 B 仓库」的竞态；GitLab / Gitea 请求补 20 秒超时与列表分页——超过 30 条不再静默截断、坏网络不再无限转圈。
- 交互防线：Ctrl+Shift+F / Ctrl+L 快捷键失败补提示；冲突解决器「全部采用我方 / 对方」与 stash 行内丢弃补确认；命令面板 Git 命令在未打开仓库时置灰。
- ESLint 接入 react-hooks 规则；TypeScript 目标升级 ES2022，8 处异常重建补全 `cause` 链（诊断不再丢失底层错误）。
- 生产构建附带 sourcemap：用户反馈的报错堆栈可还原为可读调用栈。

## 工程与维护

- **发版自动化**：`bump-version` 一条命令改齐五处版本号并复跑校验；发版说明缺失在打标签前即被拦截（此前会静默发出空说明的 Release）。
- **供应链收紧**：全部 GitHub Actions 钉到 commit SHA；接入 Dependabot 三生态周更；CI 同引用旧跑自动取消。
- 移除已被工作区审查取代的旧版独立审查视图及专属依赖（约 3400 行死代码）。
- 依赖更新：tauri-build 2.7.4、base64 0.23。

## 修复

- 中文字体回退补充微软雅黑字体栈。
- 历史与提交编辑器面板宽度独立保存；引用溢出菜单与说明文字字号统一。
