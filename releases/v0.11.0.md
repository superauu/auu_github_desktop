# AuuGit v0.11.0 · Jenkins CI 集成

本版新增独立 Jenkins 集成，可以在 AuuGit 中查看构建、阶段与日志，并触发或取消构建。现有 GitHub Actions 构建与发布流程继续保留。

## Jenkins

- 通过 `ci-cd` domain 接入 Jenkins，与代码托管平台和工作项来源分别绑定；同一个仓库可以继续使用 GitHub 托管，同时选择 Jenkins 作为 CI 来源。
- 支持连接自建 Jenkins、选择 Job、查看构建状态和阶段结果，以及读取和持续刷新构建日志。
- 支持填写 Job 参数触发构建，取消排队任务或运行中的构建；操作按插件声明的 domain 与能力进行校验。
- 连接凭证存入系统凭据管理器，重启后可恢复连接；本地保存连接配置与仓库绑定。
- 清理日志中的 Jenkins ConsoleNote 和终端控制字符，保留增量日志游标，改善长日志阅读。

## 界面与修复

- CI 页面沿用现有面板、标题、计数与滚动区域样式，工作流侧栏支持拖拽调整宽度并保存。
- 构建列表与阶段区域使用独立标题、背景和间隔，强化上下分区。
- 修复英文界面中提交历史搜索范围下拉框的箭头与文字重叠。

## 开发与验证

- 提供仅供开发使用的 Docker Jenkins 环境与模拟 Pipeline，覆盖成功、失败、不稳定、长时间运行和大量日志等情形。
- 补充 Jenkins 适配器、界面和真实本地服务冒烟检查；修正原生集成冒烟在启动恢复凭证期间的异步等待。

---

Version 0.11.0 adds Jenkins through the independent `ci-cd` domain: build status, stages, live logs, parameterized dispatch, and cancellation of queued or running builds. Credentials use the OS credential store. The CI view gains consistent panel styling, a resizable workflow sidebar, and clearer separation between builds and stages. Existing GitHub Actions build and release workflows remain in place. A development-only Docker Jenkins fixture supports integration testing.
