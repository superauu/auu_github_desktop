# AuuGit v0.4.1 · 授权与右键菜单改进

## 仓库授权

- 仓库授权弹窗的标题、正文、允许／取消按钮及系统目录选择标题跟随应用的中英文设置。
- 授权成功后才切换仓库；取消授权时保留原仓库、提交草稿和已打开的标签页，不再误报打开成功。
- 启动恢复、最近仓库、克隆、初始化及工作树入口正确处理授权取消，可以再次重试。
- 防止旧的启动恢复请求在用户选择了其他仓库后重新激活旧仓库；关闭标签页或撤销授权后，拒绝打开备用仓库时不会留下错误的活动仓库。
- 通过系统目录选择器主动选定目录仍视为授权，已经授权的目录不会重复弹窗。

## 统一右键体验

- 屏蔽浏览器默认右键菜单，保留分支、文件和提交记录的业务操作菜单。
- 代码、差异、追溯、日志与文本选区提供玻璃样式的复制菜单；虚拟列表可复制当前显示内容。
- 输入框提供撤销、重做、剪切、复制、粘贴和全选，操作时保留原选区；密码框不提供复制和剪切。
- 文本菜单跟随中英文设置，在弹窗内保持正确的位置和焦点；按 Escape 先关闭右键菜单，保留弹窗。

## 显示修复

- AI 提交规划的文件分组下拉框为箭头保留独立空间，长标题省略显示，悬停可查看完整标题。
- 下拉框在窄窗口下自动换行，保持深浅主题显示一致。

## 验证

- 203 项前端回归测试，包含授权拒绝、重试、旧请求失效及仓库状态保留检查。
- 网页预览验证代码复制、输入框剪切／粘贴、撤销／重做、既有分支菜单及弹窗内 Escape 行为。
- Windows 发布流程生成 NSIS、MSI、便携程序及带签名的自动更新元数据。

---

This patch localizes repository consent dialogs, keeps the current workspace intact when permission is declined, and prevents stale restore requests from reopening a repository. Browser context menus are replaced with glass text actions while repository menus remain available. It also fixes truncated commit-group selectors and menu focus and dismissal inside dialogs.
