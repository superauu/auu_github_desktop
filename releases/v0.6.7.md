# AuuGit v0.6.7 · 以 GPL-3.0-or-later 开源发布

## 新功能:崩溃报告（严格 opt-in）

- 设置 → 通用新增「崩溃报告」开关，默认关闭，切换即时生效、无需重启。
- Rust 与前端双端客户端常驻：开关关闭时事件在本地直接丢弃，不产生任何网络流量。
- 开启后仅上传错误堆栈、应用版本与系统类型；上报前把用户主目录替换为 `~`，不包含仓库内容或个人信息。
- 本地开发构建与浏览器预览不启用；签名端点经编译期注入，release 标记为 `auugit@版本号`，按版本归组的 crash-free 率可第一时间发现坏版本。

## 新功能:第三方许可清单随发布分发

- 每次发布附带 `THIRD-PARTY-NOTICES-<平台>.md`：覆盖 254 个 npm 依赖与 596 个 Cargo 依赖，含按内容去重的 425 段许可文本；本地确实没有附带文本的包如实列出并附上游链接。
- 可用 `npm run notices` 在本地复现；生成物不进仓库，由 CI 在构建产物收集后生成。

## 开源合规

- 项目以 **GPL-3.0-or-later** 发布：新增 LICENSE 全文、`package.json` 许可字段、安装包内置许可文件。
- 新增贡献条款（CONTRIBUTING.md）、漏洞报告入口（SECURITY.md）、代码签名政策节，README 新增「隐私与 AI」披露：本机存储、凭据走系统原生凭据库、AI 请求直连用户配置的服务商无中间服务器、崩溃报告 opt-in。
- 仓库 About 与 Topics 完善（git-client / tauri / desktop-app / react / rust）。

## 修复

- invokeError：消息为空的 Error 不再被 JSON 序列化成 `{}` 当作错误消息，回落到调用方的 fallback 文案。
- e2e：总览 fixture 拦截审核证据采集的 diff 请求，消除「查看变更」路径上网络护栏的偶发误报（慢环境竞态）。

## 测试

- 单元/集成测试 564 → **592**：补齐 themeStore（system 解析、OS 配色监听清理、View Transitions 与 reduced-motion 双路径、存储异常韧性）、useGitOperationStatus（15 秒等待提示，假时钟验证）、ImageDiffService（vite dev server + 真实临时仓库读取 `/api/git-image`）与 invokeError 全拒绝形状。
- e2e 52 → **61**：提交前审核视图首次端到端覆盖——代码块审核与意见闭环、文件级/筛选/批量审核共用记录、文件列表方向键跨分组、提交提醒两条出口（继续提交/返回审核）、内容变化后审核记录不沿用的安全属性；文本右键菜单（快照-恢复-全选）契约。
- Rust 45 → **46**：崩溃上报的门控与路径清洗（关闭必丢弃、开启后主目录必被替换、堆栈文件名保留）。

## 验证

- 592 项 node 测试、61 项 e2e、46 项 Rust 测试全绿；lint/tsc 零告警。
- 发布例程 `check:release` 版本一致性通过（应用 0.6.7 / Tauri 2.12 线）。

Headline changes of v0.6.7: AuuGit ships as GPL-3.0-or-later open source — with an opt-in crash reporting pipeline (off by default, local paths scrubbed, per-release crash-free tracking), third-party license notices attached to every release, and the pre-commit review flow covered end to end by Playwright for the first time (hunk approvals, issue loops, commit reminders, and the stale-evidence safety property). The test base grows to 592 node + 61 e2e + 46 Rust tests, all green.
