# AuuGit v0.6.5 · 多仓库总览重构为紧凑桌面工作台

## 新功能:总览页桌面化重设计

- **对齐全局桌面范式**:移除网页式大标题、副标题与大数字指标卡,改为与提交历史/工作区一致的「扁平工具条 + 粘性列头 + 密集列表」布局;信息密度提升约一倍,默认窗口下一屏容纳更多仓库。
- **单行工具条**:刷新/停止合并为同一位状态按钮;「已读取 n / m」常驻;搜索框与筛选下拉压缩到 28px 档位。
- **计数筛选芯片**:需要处理 / 待推送提交 / 冲突文件三个紧凑计数芯片,点击即筛选、再次点击恢复全部;冲突计数以危险色、待推送以品牌色高亮,替代原四张大卡。
- **密集仓库行**:24px 仓库图标、当前仓库品牌色左条与「当前」徽标、分支·路径单行元信息、inset 细分隔线;行尾 24px 操作钮(查看变更 / 查看历史 / 展开详情)。
- **详情面板压缩**:展开后三列小面板(工作区计数 / 分支与跟踪 / 持续集成),数字 16px;读取时间与重读、打开 CI 收进底部一行。

## 行为说明

- 总览页「连接 GitHub」按钮现已接入登录弹窗(此前该入口不打开任何对话框);未连接账号时 CI 列显示「未连接账号」。
- 同步行只显示非零计数:仅落后时不再出现「0 个待推送」噪声。
- 窄窗口(容器 ≤1050px)隐藏列头、单元格显示字段标签;≤640px 收为两列;工具条自动折行,无横向滚动。
- 「再显示 24 个仓库」分页按钮与数据说明(页尾 details)保持原行为;失效 i18n 键(overview.subtitle/repoCount)已清理,中英文案全量覆盖。

## 修复

- 列头与行内容列错位:行操作列由 `auto` 改为固定轨道,列头空列不再导致 fr 分配不一致。
- 展开详情中的 CI 检查目标(引用 + 短 SHA)与错误详情保持可读;重新读取按钮在读取期间禁用。

## 验证

- 564 项 node 测试全绿;Playwright 52 项 e2e 全绿(总览 8 项含单仓库、窄视口、浅色主题场景;历史/Issues 视觉基线零漂移);tsc 与全仓 ESLint 零告警。
- 内置浏览器四组合实机走查:暗色/浅色 × 中文/英文,无混排、无横向溢出;600px 窄容器与 1500px 宽屏布局逐一截图核对。
- 发布例程:`check:release` 版本一致性通过(应用 0.6.5 / Tauri 2.12 线)。

---

Headline change for v0.6.5: the multi-repository overview is redesigned into a compact desktop workspace matching the app's flat-toolbar language — a single-row toolbar with refresh/stop toggle, a live read counter, three clickable count chips (needs attention / unpushed / conflicts) that filter with one click, a sticky column header, and dense rows with inline actions. Repo errors and permission prompts stay inline; the expanded details panel is tightened to three small columns. Also fixes column misalignment between header and rows, drops the "0 unpushed" noise, and wires the Connect GitHub button to the auth dialog. 564 node tests and 52 Playwright e2e tests pass, bilingual coverage verified in dark and light themes, release version checks verified.
