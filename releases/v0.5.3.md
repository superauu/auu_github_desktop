# AuuGit v0.5.3 · 英文界面布局加固与标签排序

## 修复

- **英文界面窄窗口布局**：设置 → GitHub 账户的用户信息卡片在窗口较窄时，"Connected" 徽章被截断（"Conn…"）、按钮互相挤压、用户名被挤成细缝——现在卡片可换行、徽章完整、用户名保底 64px、极窄时徽章换行到名字下方；设置左侧导航标题与各项标签在任何窗口宽度下优雅降级。
- **标签列表排序**：原按字母序排列（最旧的 v0.2.0 在最上方，且 v0.3.10 会错排在 v0.3.9 之前），现按语义化版本降序——最新版本在最上方，与提交历史方向一致；rc 预发布排在对应正式版之后，非版本命名的标签按打标时间降序。

## 验证

- 316 项前端回归测试全绿（新增标签排序专项 3 项），tsc 与 eslint 零告警。
- 英文界面全量巡检：程序化截断扫描覆盖三档窗口宽度（1440/1120/760）下的全部主视图与弹窗（设置、仓库工具、命令面板），无截断/溢出。

---

Hardens the English UI for narrow windows (the GitHub account card no longer truncates the "Connected" badge or squeezes the username into a sliver; settings navigation degrades gracefully) and fixes tag list ordering: tags now sort by semantic version descending (newest on top, matching the history view; pre-releases sort below their final release, non-version tags fall back to tag date). Test coverage grows to 316 cases, with a three-width programmatic truncation sweep across all views and dialogs.
