# AuuGit v0.13.0 · Gitee 插件与分支比较

本版接入第七个托管平台 **Gitee（码云）**，新增**分支间比较视图**，并对安全策略、提交体验与可访问性做一批修整；Issue 编号契约放宽以容纳 Gitee 的字符串编号。

## Gitee（码云）托管插件

- 集成设置新增 Gitee 平台：**个人访问令牌**直连 `https://gitee.com`（令牌存系统凭据链），`gitee.com` 远端自动识别平台并绑定账号。
- **合并请求**：列表（编号 / 分支 / 作者 / 状态徽标）、详情（检出分支、网页查看）、**评审**（批准 + 行内评论；Gitee 平台无「请求修改」，按钮按能力位如实隐藏）、**合并**（普通 / 压缩 / 变基，对应 Gitee 的 `merge / squash / rebase`）、关闭。
- **Issue**：列表筛选、详情（负责人 / 标签 / 来源链接）、评论、关闭与重开——与 GitHub / GitLab / Gitea 在同一页面。
- **能力边界如实声明**：Gitee Go 流水线走未公开契约的独立通道，本版不接入 CI（CI 入口自动隐藏）；Issue 编号为平台随机字符串（如 IKWTPH），分支命名、外链与评论全部按字符串编号贯通。
- 真机联调：gitlab.com 同款验收流程，评论 / 批准 / 关闭 / 重开 / 合并等全部写操作在 Gitee 侧经 API 二次核实落地。

## 分支比较视图

- 分支右键新增「**与当前分支比较**」：弹窗内任意两个本地分支做三点差异（`base...head`），左侧文件清单（A/M/D/R 状态字母、重命名 `旧 → 新`），右侧逐文件 unified / split diff，带查找与字号控制。
- 方向可交换；基准与对比为同一分支时给出提示。新增 `getRefFileDiff` 服务方法（ref 间逐文件 diff），真仓库测试锁定双向语义。

## 提交体验

- 提交动作区四个按钮合并为两个**记忆型 split button**：主按钮执行上次的选择方式（提交 / 暂存提交），下拉随时切换默认动作——下拉与菜单项不再随提交条件禁用。
- AI 生成提交说明的**本地规则引擎**（未配置 API 时的兜底）改为跟随界面语言，英文模式下不再产出中文提交信息。

## 修整与安全

- **Git 选项策略封锁改双向匹配**：堵住 `--strategy-option=ours` 这类「扩展走私」（`--strategy` 被封但其长扩展名此前可穿透）；`merge -X` 一并拒绝，`rebase -X` 为既有设计保持放行——Rust / TS 镜像与测试三面锁定。
- **Gitea 接入真实取消工作流端点**（`POST actions/runs/{run}/cancel`）替换硬编码 throw，老版 Gitea 404 走错误提示。
- GitQueue 只读命令清单与 Rust 白名单对齐（移除白名单没有的 `diff-tree` / `help` 死项）；快捷键标注与实际绑定一致（Issues 为 Alt 5）；冲突解决器补齐 aria 可达性（可点击行键盘操作、图标按钮标签、加载 / 错误语义角色）。
- 无 CI 能力的托管插件（如 Gitee）不再触发 PR 视图整页错误：commit-checks 调用按能力位门控。
- 多仓库总览入口移至顶栏品牌区（全局功能不再混入仓库导航）；远程仓库支持重命名。

## 测试

- node 全量 **723** 项、Rust 测试 + clippy `-D warnings`、e2e integrations **3** 项与全部既有规格绿；新增 Gitee 客户端用例锁定实测契约（`access_token` query 鉴权、PUT 合并、Issue owner 级更新路径、patch 对象形态）。
- i18n 中英双语零混排；`CollaborationIssue.number` 放宽为 `number | string` 并抽共享校验 `isValidIssueNumber`（正整数或平台字符串标识）。

---

Version 0.13.0 adds Gitee (码云) as the seventh hosting plugin — pull requests (list, detail, review with approve + inline comments, merge with merge/squash/rebase, close) and issues (list, detail, comment, close, reopen) over a personal access token stored in the OS keychain; Gitee Go CI is intentionally not declared (undocumented channel), and Gitee's random string issue numbers flow through the whole app after widening `CollaborationIssue.number` to `number | string`. It also introduces a branch-compare dialog (any two local branches, three-dot diff with per-file unified/split view and swap), memory-type split buttons in the commit action area, and hardening: bidirectional option blocking catches `--strategy-option` smuggling (merge `-X` rejected, `rebase -X` preserved), a real Gitea cancel-workflow endpoint, GitQueue/Rust allowlist re-sync, shortcut label fixes, and conflict-resolver accessibility. Verified against real gitlab.com and gitee.com with all write operations double-checked via their APIs.
