# AuuGit v0.8.0 · 外部系统完全插件化

## 新功能：外部系统完全插件化

- GitHub、GitLab、Gitea / Forgejo、Sentry 全部重构为可插拔插件：不连接、禁用或在构建时移除任何一个平台，本地 Git 功能完整可用，其余平台不受影响。
- **GitLab / Gitea 升级为完整工作流**（原只读入口退役）：Issue 查看 / 新建 / 编辑 / 评论 / 关联分支、合并请求创建 / 评审 / 合并 / 关闭、CI 流水线查看 / 任务日志 / 手动调度 / 重跑 / 取消（Gitea 按平台 API 能力禁用取消），与 GitHub 共用同一套视图。
- 构建与运行时双层插件管理：构建可用 `AUUGIT_PLUGINS=gitlab` 只装配 GitLab、`AUUGIT_PLUGINS=none` 产出纯本地 Git 前端；运行时在 设置 → 集成 勾选启停插件，禁用不清除已保存的账号与凭证，重新启用后自动恢复会话。
- 界面按能力驱动：导航与操作按钮由插件声明的能力（读写任务、评审、合并、日志、调度等分别授权）控制显隐与禁用，禁用操作均有可见原因；能力缺失页面显示统一占位与指引。
- 平台语义得到尊重：GitLab 支持 typed inputs 手动调度、SHA 合并冲突校验、行内讨论（含重命名文件双路径）；Gitea 走原生合并 API 与 changed-files + 文本 diff 组合；运行中任务日志实时刷新（GitLab trace / GitHub 等待态 / Gitea 按日志 API 可用性）。
- 统一连接入口：设置 → 集成 按域分组连接全部平台（服务地址 + 个人访问令牌，GitHub 另有平台设备授权），多账号管理、实例隔离、自建服务器 `/gitlab` 路径前缀支持。

## 传输与安全硬化

- 新增统一 Provider HTTP 传输（Rust 侧实现）：不跟随重定向（签名下载 URL 不携带凭据）、响应按流限制 32 MiB 提前中断、默认 30 秒总超时、请求级取消（含取消抢先到达语义）、请求头 fail-closed 校验并拒绝走私头。
- CSP 收编：`connect-src` 不再逐平台列举域名，全部平台 API 经 Rust 代理；`img-src` 保持 `https:`（自建实例头像可用，拒绝明文 http）。
- 凭证只存操作系统凭据管理器，配置文件不含令牌；历史 Keyring 槽位原样沿用，升级零迁移、零令牌拷贝。
- GitHub 原生协议（设备授权、任务日志下载）由 `plugin-github` Cargo feature 门控，`--no-default-features` 构建不编译、不注册相关命令。

## 行为说明

- 升级完全兼容：旧 GitHub Profiles、forge 账号、仓库远程配置自动识别沿用；仓库协作远程优先读取 `auugit.collaborationRemote`，缺失时回退旧配置。
- 仓库切换 / 账号切换 / 令牌轮换 / 插件启停 / 断开连接均即时清空域数据并作废在途请求，不同实例不借用凭证；fork 推送不会误观察 upstream 的 CI 状态。
- 侧边栏与页面术语统一为「合并请求」（Merge requests）。
- GitHub 插件当前仅支持 github.com；GitHub Enterprise 需后续扩展该插件。
- 读取失败、403、未实现能力均明确反馈，不伪造评审、合并或流水线成功。

## 测试

- 单元 / 集成测试 616 → **653**：新增插件隔离（esbuild 依赖图断言 GitLab-only / 无插件构建不含其他平台实现）、能力声明双检查（方法存在 + 能力声明）、共享传输（本地真实 HTTP 服务覆盖敏感头 / 重定向不跟随 / 响应上限 / 取消）、集成域治理与账号生命周期专项。
- Rust 测试 50 → **55 + 54**（默认与无 GitHub 两档 feature 各自全绿）：Provider 传输校验、取消语义、Keyring 槽位兼容。
- 原生链路验收 **16 项**：真实 Windows WebView + IPC + 系统凭据槽位，覆盖登录、Issue、合并请求创建 / 差异 / 评审 / 合并、实时日志、调度 / 重跑 / 取消、403 可见、重定向拦截、取消确认、32 MiB 上限与凭据清理。
- e2e 浏览器回归 **64 项**全绿（含 GitLab 完整工作流：Issue 评论 → 关联分支 → 创建合并请求 → 合并 → 任务日志，断言全程无 GitHub 网络请求）。

## 验证

- 653 项 node 测试、55 + 54 项 Rust 测试、64 项 e2e、16 项原生链路验收全绿；clippy（CI 同款 `-D warnings`，两档 feature）零告警；GitLab-only Windows 桌面可执行文件与无插件前端构建通过；发布例程 `check:release` 版本一致性通过（应用 0.8.0 / Tauri 2 线）。

---

Headline changes of v0.8.0: full pluginization of external systems — GitHub, GitLab, Gitea/Forgejo and Sentry become optional plugins (build-time `AUUGIT_PLUGINS` profiles plus runtime enable/disable with auto session restore); GitLab and Gitea graduate from read-only views to the complete collaboration workflow (issues, merge requests with review/merge, pipelines with dispatch/rerun/logs, respecting per-platform semantics such as no REST cancel on Gitea); capability-driven UI gating with visible disabled reasons; a hardened provider HTTP transport (no redirects, 32 MiB streamed cap, 30 s timeout, cancellation, fail-closed headers) behind a collapsed CSP; credentials stay in the OS keyring with legacy slots untouched. Test base grows to 653 node + 55/54 Rust (two feature profiles) + 64 e2e + 16 native-link acceptance checks, all green.
