# AuuGit v0.6.6 · 全应用 UI 体系归一

## 新功能:多仓库总览桌面化重构

- **紧凑工作台布局**:移除网页式大标题与大数字指标卡,改为「扁平工具条 + 粘性列头 + 密集列表」;需要处理/待推送/冲突三枚计数芯片点击即筛选、再点恢复全部。
- **详情面板精修**:展开详情改为竖分隔三列骨架;工作区计数带语义色点(0 值自动降权);分支接入品牌色徽标;CI 与主行同一徽标语言,消除重复文案。
- 修复列头与行内容错位、同步行「0 个待推送」噪声;「连接 GitHub」接入登录弹窗。

## 新功能:Issues 页桌面化重构

- 两行网页式页头(大标题 + 带标签表单)收为单行扁平工具条:刷新、新建、仓库范围与 28px 内联搜索/状态/标签/负责人控件。
- 圆角卡片列表改为密集行:inset 分隔线、悬停着色、选中品牌色左条,标题行前加开/闭状态色点。

## 统一:按钮与工具条体系

- **按钮尺寸阶梯补齐**:新增 28px `toolbar` 档与 `icon-sm`/`icon-xs` 图标档,全项目 133 处尺寸覆写归位;同一档位字号统一 12px/13px,不再各页打架。
- **主按钮换款**:亮青实心色块改为青色调 tinted 款(青底 + 青描边 + 青字),与徽标/芯片同一画法;新增 outline-success/outline-danger 语义变体,清理 emerald/rose/cyan 任意色与霓虹辉光残留(冲突解决器的「我方/对方」双栏领域色保留)。
- **工具条一处定义**:新增全局 `.app-toolbar`/`.app-toolbar-group`,总览/Issues/PR/Actions 四页共用同一高度(34px)与组间距,消除跨页 2px 错位;PR/Actions 头部从 40px 半透明混搭归一,PR 分段筛选接入全局分段控件语言。
- **选中态统一**:导航/分支树/总览/历史/Issues 五处选中高亮统一为「青 12% tint + 2px 青色左条」,移除深蓝底与青描边混用。

## 行为说明

- 图标随按钮档位统一 12/14px;冲突解决器的 emerald/cyan 为「我方/对方」领域色系,与列头高亮联动,有意保留。
- README 总览描述同步(卡片→行、补计数芯片筛选)。

## 验证

- 564 项 node 测试全绿(修复 1 处因类名归位失效的测试锚点);Playwright 52 项 e2e 全绿,issues 视觉基线按新设计重生成,其余零漂移;lint/tsc 零告警。
- 暗色/浅色 × 中/英四组合实机走查,600px 窄容器与 1440px 宽屏逐一截图核对;总览/Issues/PR/Actions 四页工具条实测同高同位。
- 发布例程:`check:release` 版本一致性通过(应用 0.6.6 / Tauri 2.12 线)。

Headline changes of v0.6.6: the whole UI speaks one language. The multi-repository overview is rebuilt as a compact desktop workspace (flat toolbar with clickable count chips, sticky column header, dense rows, refined three-column detail panel), the Issues page drops its web-style header and card list for the same toolbar + dense-row pattern, and a global design system locks buttons (five-size ladder with a new 28px toolbar size, tinted primary buttons, semantic outline variants), toolbars (one shared 34px `.app-toolbar`), and selection states (cyan tint + cyan accent bar everywhere). 564 node tests and 52 Playwright e2e tests pass, bilingual coverage verified, release checks verified.
