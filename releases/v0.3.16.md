# AuuGit v0.3.16

本次更新修复推送目标选择与设置回显，并让 AI 批量提交的执行进度更清楚。

## 修复与改进

- **精简推送按钮**：按钮仅显示目标 remote，例如“推送 → origin”；完整目标分支保留在悬停提示中。

- **单远程直接推送**：只有一个远程仓库时，普通推送和 AI 批量提交后的推送自动使用该远程及解析出的目标分支。强制推送仍需确认；工具栏更多菜单保留“选择推送目标…”入口，可手动修改目标分支。
- **设置保存与回显**：重新打开推送窗口时，正确显示此分支已保存的默认推送远程和跟踪分支状态。推送成功后保存选项；取消勾选当前目标可清除相应设置，保留其他目标的配置。设置保存失败会单独提示，保留推送成功结果。
- **防止重复推送**：推送处理中连续点击不会重复排队相同仓库的推送操作。
- **批量提交进度**：正确识别 Git 全局选项后的真实操作，显示当前分组标题、已完成提交及当前阶段耗时。耗时较长时区分提交检查/签名与网络推送等待，避免将提交过程误认为推送卡住。

## 关于提交耗时

每个提交仍会执行仓库配置的提交检查和签名。若仓库的提交钩子每次运行全项目检查，多个分组会重复执行这些检查。全部提交成功后只推送一次；本次更新不会绕过仓库检查。

## Validation

- 174 automated regression tests passed, including a real four-group Git batch with per-commit hooks, saved-remote/tracking persistence and clearing, chooser behavior, and duplicate-push protection.
- Release version consistency and TypeScript / frontend production build checks.
- Windows installers and signed automatic-update metadata are generated by the release workflow.

This release skips destination selection for ordinary single-remote pushes, restores saved push and tracking settings in the chooser, supports clearing settings for the selected destination, prevents duplicate pushes, and improves batch-commit progress with accurate Git phases and per-phase timing. Repository hooks and signing remain enabled for every commit; pushing runs once after all commits succeed.
