# AuuGit v0.4.3 · 评审流与开发者工作流升级

## Pull Request 评审（应用内完成评审闭环）

- PR 列表新增"评审"入口，弹窗内提供对话时间线（评论与评审按时间合并、状态徽标区分 Approve / Changes requested / Commented / Dismissed）。
- Files 页按文件渲染 diff 补丁，支持在具体 diff 行上锚定行内评论：添加草稿、移除、随评审一次性提交。
- 提交评审支持 Approve、Request changes（必填总评）、Comment 三种类型；已合并/已关闭的 PR 自动转为只读，无权限时隐藏评审提交区并给出提示。
- 超大 PR 有护栏：文件数超 300 提示截断，单文件补丁超 500 行按 hunk 折叠。

## 多账号 Profile

- 支持登录多个 GitHub 账号并一键切换：账号菜单显示当前身份，可添加账号、切换、管理与退出。
- 每个账号的 token 在系统凭据管理器中独立槽位存储；旧版本用户的无缝迁移（默认账号沿用既有凭据，零拷贝）。
- 切换账号时自动清理所有者/仓库绑定与 PR、CI 状态；添加账号取消时自动回退到原账号。

## 可视化 Bisect 向导

- 提交历史工具栏新增 Bisect 入口：三步向导（选择好坏范围 → Good/Bad/Skip 测试循环 → 定位首个坏提交）。
- 显示当前候选提交与剩余步数估算（标注为估算值）、可折叠的二分过程日志；随时可重置或恢复进行中的会话。
- 工作区有未提交改动时给出明确警告；`bisect run`、`bisect replay` 等可执行外部命令的子命令在策略层被永久封禁。

## 冲突三方对照

- 冲突解决器新增整文件"三方对照"面板：基线/我方/对方三栏并排，冲突区域高亮，点击高亮跳转到对应解决块。
- 每个冲突块可单独展开三方对照；基线区域按上下文锚点定位（未精确匹配时标注"按位置推算"），add/add 冲突等无基线场景有明确占位。

## 每提交仓库快照

- 提交详情弹窗新增"仓库快照"模式：浏览该提交时点的完整项目文件树（虚拟化渲染、路径筛选、目录折叠、文件大小）。
- 点击文件查看该提交时点的内容（行号、字号联动，二进制/超大文件有占位说明）；属于本次提交变更的文件可一键跳转到差异视图。

## 效率与集成

- 历史搜索增强：内容搜索新增正则模式（非法正则给可读报错）与可选的路径过滤。
- 外部 diff/merge 工具：设置中登记自己的对比/合并工具（VSCode、Beyond Compare 等），工作区文件与冲突文件可右键交给外部工具打开；工具配置由后端持有，启动面只接受工具 ID 与仓库内路径，不经 shell。
- AI 生成 Release Notes：命令面板一键按提交区间（默认最后一个 tag 到 HEAD）生成 Markdown 发布说明，可复制；提交列表以定界符包裹并声明"数据非指令"。
- 仓库分组：仓库菜单按分组分区显示，行内指派/移出分组，支持组内批量 fetch；未创建分组时菜单与原版完全一致。
- 系统通知：应用失焦时，被监听的 CI 检查完成（成功/失败）弹系统通知；30 秒节流与会话去重防轰炸，点击通知聚焦窗口，可随时在系统设置中关闭权限。

## 工程与安全

- Git 参数策略新增 bisect 子命令白名单约束（仅放行无副作用的二分子命令）；推送 CI watch 的检查数据接入通知管线。
- 新增依赖 tauri-plugin-notification（系统通知）与 @tauri-apps/plugin-notification。
- 测试套件扩展至 296 项（新增快照树、搜索增强、三方对照、外部工具、Profile、Bisect、Release Notes、通知、分组九个专项套件），词典完整性测试同步覆盖全部新键。

## 验证

- 296 项前端回归测试（真实临时 git 仓库、竞态注入、假 fetch 驱动），tsc 与 eslint 零告警。
- GitHub Actions 三平台任务（Windows lint/clippy/cargo test、Ubuntu 前端跨平台）全绿；系统通知插件首次真实编译通过。
- 中英双语界面实机验证：分组菜单、Bisect 向导、快照文件树与提交内容查看、搜索模式与路径过滤、命令面板入口。
- Windows 发布流程生成 NSIS、MSI、便携程序及带签名的自动更新元数据。

---

This release completes in-app pull request review (conversation timeline, inline diff comments, approve/request-changes), multi-account GitHub profiles with isolated keyring slots, a visual bisect wizard with policy-level hardening, per-commit repository snapshot browsing, three-way conflict comparison, external diff/merge tool integration with a backend-held launch surface, AI release notes generation, repository grouping with batch fetch, and background CI system notifications. Test coverage grows to 296 behavioral cases across nine new suites.
