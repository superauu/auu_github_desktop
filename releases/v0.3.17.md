# AuuGit v0.3.17

本次更新带来黑灰色玻璃界面，改善浅色主题的按钮辨识度、AI 规划等待体验及仓库操作的安全边界。

## 修复与改进

- **玻璃界面**：导航、工具栏、工作区和弹窗采用中性灰磨砂效果；代码区域保留清晰底色。统一按钮、搜索框和视图切换控件，增强浅色主题的边框和文字对比度，并适配减少透明度设置。仓库和分支选择器保持相同高度，仓库标签页增加留白、柔和的选中标识及独立分支标识。
- **推送状态**：恢复尚未推送的提交数量。获取更新、拉取和推送按钮样式一致，有待推送提交时突出显示推送按钮。
- **提交面板**：错误提示可以关闭，技术详情保留独立滚动区域；报错及展开提交文件列表不会再将提交按钮挤出面板，关闭提示会保留草稿。
- **Git 控制台**：配色跟随深浅主题，与工作区保持一致；网页预览禁用仅桌面版支持的外部终端入口。桌面版通过原生命令打开终端，失败时给出提示。
- **AI 规划**：优化变更收集，显示准备和等待阶段，支持取消并设置请求超时，减少长时间等待时的不确定感。
- **仓库访问**：新增目录授权边界，限制文件读写及 Git 操作范围，保持克隆、初始化和工作树功能可用；支持撤销目录授权。
- **Git 参数与程序校验**：补齐 clone/init 的短选项配置绕过及合并策略过滤，检查自定义 Git 程序来源，并限制目录浏览接口范围。
- **其他安全修复**：图片读取复用受控 Git 执行流程，文本读取设定大小上限，文件保存使用原子替换；校验 OAuth 验证网址，打包本地字体并收紧生产内容安全策略。
- **持续检查**：主分支推送和拉取请求均运行检查，包含前端代码规范、回归测试及 Rust 检查。

## Validation

- All 193 automated regression tests passed, covering Git policy, repository authorization, AI planning, push behavior, draft preservation and terminal availability.
- Release versions, lint and the TypeScript / frontend production build are checked before tagging.
- Windows CI checks the Rust backend, Clippy warnings and backend tests before release tagging.
- The release workflow builds Windows installers and signed automatic-update metadata.

---

This release introduces a neutral glass interface with clearer light-theme controls, restores push counts, improves AI planning progress and cancellation, keeps commit actions visible when errors occur, aligns the Git console with the active theme, and strengthens repository authorization, Git argument validation and local file access.
