# AuuGit v0.6.1 · 更清晰的审查流程与意见闭环

## 审查流程

- **最终改动作为主入口**：原「净变更」更名为「最终改动」，直接查看检查点到当前最新版本的最终结果。
- **提交记录按需查看**：提交列表默认折叠并标注「可选」。单个提交的「已查看」记录单独保存，本轮完成度始终按最终改动计算。
- **完成本轮审查**：检查最终代码并处理意见后，即可推进检查点，无需逐个提交再做标记。各提交中的未解决意见仍会统一提醒，完成后支持撤销。
- **分级通过与增量复审**：支持按文件、代码块记录通过状态；新提交到来时保留未变化内容的通过记录，变化部分重新检查。图片和二进制文件也支持文件级通过。

## 审查意见与报告

- 意见支持「待处理 / 待复核 / 已解决 / 已过期」，保留原始代码上下文，方便核对后续修复。
- 支持勾选多条意见批量解决、将当前筛选结果全部标为已解决，以及批量重新打开；操作后可撤销。
- 报告汇总最终改动和各次提交中的意见，保留来源、文件、行范围与原文，支持复制给 AI 调整。
- 意见中的原始代码与报告代码片段显示红绿差异高亮；修复报告内容无法滚动、下拉菜单文字对比度不足的问题。

## 稳定性

- 修复收起左侧导航时的 React Hook 顺序错误，避免视图崩溃。
- 本地保存失败时保留内存中的进度并提示重试，避免保存异常阻断差异查看。
- 差异读取失败后可直接重试当前文件，同时防止重复加载。
- 历史进度清理保护未解决意见的最新副本，避免其他活跃分支产生大量记录时误删待处理意见。
- 审查记录按仓库、分支、基准、最新版本和差异来源隔离；撤销与批量操作校验当前审查范围。

## 使用说明

推荐流程：检查最终改动 → 处理审查意见 → 完成本轮审查。需要追溯修改过程时再展开提交记录。

图文指南：[审查视图使用指南](https://github.com/superauu/auu_github_desktop/blob/v0.6.1/docs/review-guide.md)。

---

This release clarifies the review workflow: Final changes is the main entry, individual commit history is optional, and round progress always reflects final file approvals. It adds incremental review, finding statuses with original code context, scoped bulk resolve/reopen actions with undo, and highlighted, scrollable review reports. It also fixes sidebar-collapse crashes, makes local-save failures recoverable, enables retrying failed diff reads, and protects unresolved findings during history cleanup.
