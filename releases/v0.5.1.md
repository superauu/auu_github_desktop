# AuuGit v0.5.1 · 账号菜单修复

## 修复

- 桌面版登录后，账号菜单的"添加账号 / 管理账号"点击无反应：点击"添加账号"会让整个菜单在点击瞬间同步卸载（认证态翻转触发条件渲染），其卸载清理与认证/设置弹窗的挂载在 WebView2 上相撞，弹窗被瞬间关闭——表现为点击没反应。现延迟到菜单卸载完全落定（30ms，无感知）后再打开弹窗。
- 同型隐患同步加固："更多仓库操作"菜单中的新建分支、忽略规则、工作树三项（同样从菜单直接打开弹窗）。

## 验证

- 313 项前端回归测试全绿，tsc 与 eslint 零告警。
- 真实指针点击逐帧探测：添加账号 / 管理账号 / 新建分支三项弹窗均打开并保持。

---

Fixes the desktop-only issue where "Add account / Manage accounts" in the account menu appeared unresponsive after signing in: toggling authentication state synchronously unmounted the whole menu mid-click, and its teardown raced the dialog mount on WebView2, instantly closing the freshly opened dialog. Dialog opens are now deferred until menu teardown fully settles (30ms, imperceptible). The same hardening is applied to the three dialog-opening items in the repository actions menu (new branch, ignore rules, worktrees).
