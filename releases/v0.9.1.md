# AuuGit v0.9.1 · 面板工作区收尾

本版是 v0.9.0 工作区重设计的收尾：统一列表/详情的计数口径、面板内状态提示与详情头规格，并把左右分栏的分隔条升级为指针捕获实现。

## 面板与详情统一

- 计数口径组件（PanelCount）：列表与面板计数统一展示，并按语境向悬停提示与读屏说明口径——符合筛选的总数（含未加载项）/ 已加载且符合筛选 / 当前已加载 / 工作区变更（暂存与未暂存分别计数）/ 已加载评论数。分页加载的条数不再被误读为总数，数字按界面语言本地化。
- 面板内状态带（WorkspaceNotice）：加载中与失败提示收进列表面板内部，靠近内容、小字号，不改变工作区分栏；失败带自带原位重试 / 打开设置动作，替代原先横贯整页的告警条。错误源连接失败时保留健康来源的缓存行并指明失败的连接；Errors 同步中也有面板内提示。
- 详情头统一：合并请求评审、Issue、错误详情共用同一组规格（紧凑标题、元信息行、28px 动作按钮组），正文标题可选中复制，长分支名 / 仓库路径截断并有悬停提示。
- 选中态与列表行：变更文件列表选中行改为平台统一的 primary/12 底色 + 2px 强调色左条（与 Issues / PR 列表一致）；空态图标居中对齐文本并对读屏隐藏；Issues 详情头改用共享规格，窄屏间距收紧。
- 分隔条重写为指针捕获（Pointer Events）：拖拽期间句柄获得焦点，鼠标与触摸拖拽更稳，系统取消（pointercancel）与窗口失焦都会干净复位，方向键 / Home / End / 双击复位保留。

## 合并请求列表适配窄栏

- 状态筛选从分段按钮改为原生下拉（适配 200px 最小栏宽），计数与刷新始终留位；200 / 240 / 320 / 550px 全宽度验证筛选、计数与刷新均可达且面板头无横向溢出。
- 新增中文 / 英文两种语言的最小栏宽（200px）截图基线。

## 文案

- 中文界面术语统一：Auth Token → 访问令牌、PR → 合并请求；省略号统一为「…」；CI/CD 任务面板标题带运行编号（如「运行 #12 的任务」）。中英文均无混排。

## 测试

- 单元测试 **690** 全绿（PR 状态筛选下拉与既有选择器断言适配）。
- e2e 浏览器回归 75 → **93**：新增面板工作区规格 18 项——五种工作区（变更 / Issues / 合并请求 / Errors / CI-CD）× 中文暗色 / 英文浅色截图基线、200–550px 全宽度筛选可达性、分隔条鼠标 + 触摸拖拽 / 取消 / 键盘复位、空态图标对齐、窄栏列表高度保持、分页计数口径、面板内加载 / 重试、部分来源失败时的健康行保留。
- 视觉基线按新布局重建（issue-workflow 暗色、Issues 暗色 / 浅色）；`tsc`、`eslint` 全绿。
