# AuuGit v0.6.0 · 审查视图:看住 AI 的每一次提交

> AI 负责提交,AuuGit 负责放行。这个版本为「独立开发者配合 AI 编码」的workflow带来专属的把关工作台。

## 新功能:审查视图(左侧导航「审查」,快捷键 Alt+2)

AI 编码工具全面转向 agent 模式后,「改动审查」这个关键环节反而被弱化了。审查视图把人工把关重新做成一等工作:

- **审查检查点**:每个分支记录「上次已审查到哪」(保存在仓库本地的自定义 ref 中,不参与构建、不会被推送)。首次进入有三步基准引导:跟踪分支远程位置 / 最近 N 提交之前 / 从历史挑选。
- **风险徽标(本地规则,离线可用)**:疑似密钥(私钥头、AWS/GitHub/Slack/Google 凭证、JWT、password 赋值形态,占位符自动排除)、.env 文件提交、依赖清单变更、CI 配置变更、大量删除、二进制文件。悬停查看涉及文件;只提示、绝不自动删除或阻断。
- **AI 参与徽标**:提交信息带 `Co-Authored-By: Claude/...`、`Generated with ...` 等署名的提交自动标记。
- **净变更 + 单提交双视图**:「净变更」是检查点以来所有提交叠加后的最终差异(不看过程只看结果);也可逐提交用统一/分栏视图审查,支持查找、换行、忽略空白、字号与图像对比。
- **AI 总结**:一键对整段待审范围生成总览与逐提交意图说明(需在设置中配置 AI API;本功能不随应用内置密钥)。
- **内联整理提交**:AI 喜欢拆碎提交——审查视图内直接把检查点之后的提交带入历史整理,拖动排序、Squash、Fixup;已推送提交防改写、操作前自动保存恢复点。
- **标记已审查**:看完一键推进检查点,4 秒内可撤销;推送成功后若仍有未审提交,会弹提醒并可一键标记。

## 其他改进

- 全新视图已接入主导航、Alt+2 快捷键、命令面板与快捷键速查表;中英文案全量覆盖。
- 历史整理计划接口支持显式基准(供审查视图范围锁定,超过 30 个提交提示分批)。

## 行为说明

- 审查检查点按分支保存在 `refs/auugit/review/<分支名>`;克隆到新机器后不存在,可随时用 `git update-ref -d` 删除。变基/强制推送后视图会提示重建基准,不会静默丢数据。
- 待审范围内包含合并提交时「整理提交」不可用(与历史视图同一安全边界)。
