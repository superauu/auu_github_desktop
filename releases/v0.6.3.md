# AuuGit v0.6.3 · 历史视图与图形走法重构

## 提交历史视图

- **独立「分支 / 标签」列**：分支、标签、远程引用徽标改为独立一列，不再挤占提交信息；三列头（分支 / 标签 · 图形 · 提交信息）对齐各列。
- **更高密度**：行高收紧至 30px，作者与时间等元数据贴行尾、按需显示，一屏可见提交明显增多；选中行改为扁平高亮。
- **徽标与泳道同色**：本地分支徽标随所在泳道着色，当前分支加深一档；标签保持琥珀、远程保持中性灰，徽标 → 连接线 → 节点三处同色。
- **搜索完整性**：搜索时显示「显示 N / 已加载 M」并提供一键「显示全部」。
- **详情文件过滤**：提交详情的变更文件列表新增过滤框，树形与平铺两种模式都生效。

## 图形（Git Graph）

- **新走法**：同一泳道为垂直直线；换道在子节点下方一行内完成肘弯，随后沿目标泳道垂直直下——消除跨多行的长斜线横穿，分支合并的走势与主流 Git 客户端一致。
- **几何对齐**：泳道间距 32px、图形列宽贴合实际泳道数（单泳道不再保留固定空槽），消息列紧跟图形列，节点环加粗至 2px。
- **作者头像入节点**：提交节点内嵌作者 identicon（本地确定性生成、完全离线、色相锁定品牌安全色板），不同作者一眼可辨。
- **WIP 与 HEAD**：WIP 节点对齐到 HEAD 所在泳道并竖向虚线相连；HEAD 节点以同色肘线连接到分支徽标，形成「徽标 → 线 → 节点」的视觉通路。

## 身份与安全动作

- **AI 徽标**：历史行标记含 Co-Authored-By 尾注或 AI 作者标识的提交，「AI 负责提交，AuuGit 负责放行」的工作流下先知道是谁提交的。
- **撤回 / 恢复升级为一级动作**：工具栏新增「撤回 / 恢复」（撤回上次提交 / 恢复撤回的提交），无可操作时置灰，不再藏在溢出菜单里。
- **动词组重排**：获取更新、拉取、推送、撤回、恢复、分支、贮藏、终端改为无边框微标签式按钮组。

## 工作区与侧栏

- 变更面板头部随宽度自适应：窄面板时低频操作收进「更多」菜单，新增快速贮藏入口。
- 侧栏计数徽标统一等宽数字与字重，标题样式统一，列表 / 工具切换补充提示。

## 修复

- 修复点击设置图标打开对话框后「打开设置」提示不消失的问题（对话框关闭时焦点归还触发器导致提示重新打开且悬挂）。
- 修复中文界面工具栏「撤回 / 恢复 / 终端 / 操作 / 标签」等七处未翻译，并完成全量中英文案双向核查。

## 发布前验证

- 484 项前端回归测试、40 项 Rust 测试通过；版本一致性检查、前端 lint 与类型检查通过。
- 在内置浏览器实测：四泳道复杂历史（并行特性分支 + 双合并 + 未合并分叉 + 标签）、WIP 竖向连接、徽标/连线/节点同色、AI 徽标、工具栏撤回、设置提示消失。

Windows 用户可使用应用内自动更新；macOS 和 Linux 用户请下载对应架构安装包。

---

This release reworks the commit history and graph. History gains a dedicated refs column with aligned headers, denser 30px rows, a flat selection style, search completeness ("Showing N of loaded"), and a file filter in commit details. The graph adopts the standard one-row elbow walk (no long diagonals), tighter lane geometry fitted to the lane count, author identicons embedded in nodes, a WIP node aligned above HEAD, and lane-colored badges, connectors and nodes. It adds an AI-authorship badge on commits, promotes Undo/Redo to first-class toolbar actions, and fixes the settings tooltip that stayed open after closing the dialog plus seven untranslated Chinese toolbar labels.
