# AuuGit v0.8.1 · 连接账号即启用

## 新功能：连接账号即启用

- 移除 设置 → 集成 的插件启停开关：**连接账号即启用，断开全部账号即淡出**。Issues / 合并请求 / CI 的导航入口与按钮能力只由已连接账号的平台提供；连接卡片仍始终列出全部已装配平台，保证第一个连接可建立。
- 断开最后一个账号后若停留在工作域页面，页面改为提示「连接托管平台账号后即可使用」并给出连接入口，不再误报「所选平台未提供此功能」。
- 设置 → 账号在未登录（令牌失效或平台插件被构建裁剪）时仍列出已连接账号并允许删除，残留账号不再无从收拾。
- 历史版本写入的插件禁用标记在启动时自动清除；运行时启停机制仅保留给隔离测试与故障注入，不再写入本地存储。

## 行为与修复

- 通用文案中立化：账号菜单、PR 创建提示、总览 CI 提示从 GitHub 专属措辞改为「托管账号」「连接托管平台」，GitLab / Gitea 会话下不再出现平台名错配；中文界面统一「合并请求」，清除中英混排的 "Pull Request"。
- 平台语义以活跃账号为准：PR 合并方式、评审事件、CI 实时日志、工作流派发与 Issue 平台标签在账号切换或会话恢复间隙不再借用上一个平台。
- 能力门控与插件启用口径统一：插件被构建裁剪或隔离测试停用时，残留账号不再贡献可用能力。
- 集成设置页信息层级调整；侧边栏筛选、PR 搜索与 Issue 状态下拉补齐表单 name，消除无障碍警告；孤儿 i18n 键清理。
- 全部禁用操作统一给出「当前插件不支持此操作」原因；GitHub 专属的「关闭为不计划处理」按能力声明显示。

## 测试

- 单元 / 集成测试 653 → **655**：新增「能力跟随已连接账号、最后一个账号移除后消失」与 `activeProviderId` 回退语义。
- e2e 浏览器回归 **64** 项全绿（含无 GitHub 账号的 GitLab 全流程、未连接态侧边栏）。
- Rust 侧本版无改动，沿用 v0.8.0 的 55 + 54 基线；`tsc` / `eslint` / `check:plugins` 全绿。

## 验证

- 655 项 node 测试、64 项 e2e 全绿；`check:release` 版本一致性通过（应用 0.8.1 / Tauri 2 线）。
- 未连接任何账号时侧边栏只保留本地 Git 功能；连接账号后工作域入口即时出现，断开全部账号即时淡出。
- 视觉基线已按未连接态侧边栏重建，暗色 / 浅色与 750×600、900×600、1280×720 三档视口通过。

---

Headline changes of v0.8.1: connecting an account is now the only switch — hosting plugins are enabled by having at least one connected account, so workspace entries (issues, merge requests, CI) appear on connect and fade out when the last account is disconnected; the settings page no longer exposes per-plugin toggles and always lists every bundled platform so the first connection remains possible. Disconnecting every account on a workspace tab now shows a "connect a hosting account" empty state with an inline entry point instead of a misleading capability message, and accounts whose token expired (or whose plugin is excluded from this build) can still be listed and removed. Platform-specific semantics (merge methods, review events, live logs, dispatch, issue labels) now follow the active account rather than a possibly stale session field. Test base grows to 655 node tests; 64 e2e checks, typecheck, lint and plugin-composition checks are green.
