# AuuGit v0.7.0 · 错误追踪集成（Sentry）与代码托管域化

## 新功能：错误追踪集成

- 设置 → 集成选择 Sentry，输入 Auth Token 一步连接（自托管地址收在高级选项）；Token 只存操作系统凭据链，不落配置文件。
- 左侧导航「错误」在连接建立后自动出现，徽标显示当前作用域的未解决数（99+ 截断）；按仓库 / 全部作用域切换，支持按来源连接与严重级筛选、标题与短 ID 搜索。
- 列表可调宽度（280–640px），按连接独立分页加载更多，自动轮询间隔可在设置调整（30/60/120/300 秒，默认 60）。
- 详情页：次数 / 影响用户 / 首次与最近出现 / 环境与 release 元信息条；堆栈帧点击跳转本地文件（三级置信：精确匹配 → 唯一模糊匹配 → 歧义文件选择器）；嫌疑提交；Raw data 折叠区。
- 修复工作流：一键创建修复分支（`fix/sentry-短ID-标题`）；提交自动附加中性引用 trailer（`Error-Tracking: sentry/短ID`，不使用自动关闭关键词，issue 状态由平台侧掌控）；创建 PR 时描述自动追加引用块；修复分支、提交 SHA 与 PR 回写到 issue 详情。
- AI 修复：按堆栈定位相关文件构建受限上下文（5 文件 / 单文件 8K / 总量 32K 预算，敏感文件一律跳过），生成补丁经确认后 `git apply`，不自动提交；脏工作区拒绝执行。
- 状态回写：标记已解决 / 在下个 release 解决 / 忽略，成功后列表即时更新；权限不足（403）等错误提示常驻屏幕，需手动关闭。
- 多连接独立降级：单连接同步失败保留旧数据并以页内横幅提示重试，不影响其它连接。

## 新功能：代码托管域化（GitLab / Gitea）

- 取消独立「GitLab / Gitea」导航：合并请求页成为代码托管的统一表面——GitHub 仓库维持原有深度界面；GitLab / Gitea 仓库在同一页查看打开的合并请求、详情（描述 / 评论 / 流水线状态）并在浏览器打开。
- 集成页按域分组（错误追踪 / 代码托管）：GitLab、Gitea / Forgejo 以「服务地址 + PAT」一步连接，Token 同样只存系统凭据链。
- 侧边栏「拉取请求」徽标按当前仓库平台自动切换计数（GitHub PR 数 / GitLab / Gitea 合并请求数）。
- 修复：GitLab / Gitea API 请求改走 Rust 代理——生产环境 CSP 白名单未包含自建域名，此前桌面端无法实际访问这两个平台的 API。
- 修复：外部链接与本地文件打开迁移到 opener 插件——shell 插件的 Rust open API 已被上游弃用；堆栈跳转的本地文件打开同时改走带路径校验的专用命令（原前端通道会被 github.com 专用校验器拒绝）。

## 行为说明

- 「错误」导航只在存在可用连接后出现；连接断开 / Token 失效时导航保留，由页内横幅提示。
- 快捷键收敛：Alt+5 直达 Issues（原为 Alt+6）；独立 forge 页快捷键取消。
- 只读 Token 即可使用查看类功能；状态回写需要对应写权限。

---

Headline changes of v0.7.0: Sentry error-tracking integration lands — token-only connect (keychain-stored), a scoped issue list with severity/source filters and configurable polling, local stack-frame jump with three-tier confidence, a fix workflow that creates branches and appends neutral `Error-Tracking` trailers (no auto-close), budgeted AI patching via `git apply`, and status write-back with persistent error toasts. The GitLab / Gitea menu is retired: the Pull Requests page becomes the unified code-hosting surface (per-platform badge), their APIs now route through the Rust proxy to escape CSP, and external/local file opening migrates to the opener plugin. The integrations settings group providers by domain. Test base grows to 616 node + 50 Rust tests, all green.
