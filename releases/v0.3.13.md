# AuuGit v0.3.13

本次更新重做变更列表的文件多选交互，未跟踪文件支持一键全部添加，并完善恢复点的命名管理。

## 新增与改进

- **文件批量操作**：变更列表的文件复选框改为纯选择控件，不再点击即暂存。勾选多个文件后可统一暂存、取消暂存或忽略；Shift 勾选连续选择，Ctrl / ⌘ 点击文件多选。暂存单个文件使用行尾的加号/减号按钮、空格键或右键菜单。
- **全部添加**：“未跟踪文件”分区新增“全部添加”，一键跟踪并暂存全部新文件，且只处理未跟踪文件，不会顺带暂存其他修改。
- **恢复点命名管理**：恢复中心支持为手动恢复点填写名称、给已有恢复点改名或删除。名称保存在仓库本地配置中，关联 Worktree 共享；删除只移除所选恢复点，不改变分支或工作区文件。
- **更新说明显示**：自动更新检测到的版本说明按纯文本呈现，避免 Markdown 标记干扰阅读。

## 下载说明

- Windows x64 安装版：选择 `AuuGit_0.3.13_x64-setup.exe` 或 MSI 安装包。
- 独立可执行文件：选择 `auugit.exe`。
- 安装更新前，请先保存正在编辑的内容。
