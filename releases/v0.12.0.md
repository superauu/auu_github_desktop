# AuuGit v0.12.0 · 八项 Git 能力补全

本版补齐一批桌面 Git 工作流中缺失的实用能力：全局代码搜索、补丁导出与应用、提交详情距 tag 距离、仓库统计、本机全局忽略规则、提交备注，以及 macOS / Linux 的外部终端支持；文件历史与 blame 跳转、分页一并增强。

## 全局代码搜索

- **Ctrl+Shift+G** 唤起全局搜索浮层（顶栏按钮与命令面板同入口）：按字面或正则检索工作区跟踪文件内容，支持大小写、全词、路径过滤。
- 结果按文件分组，带行:列定位与命中高亮；每条可复制行内容或用系统默认程序打开文件。
- 结果过多时截断显示前 500 条并提示缩小范围；二进制文件由 `-I` 跳过。

## 补丁导出与应用

- 提交右键「导出补丁」：使用 `format-patch --stdout` 生成补丁文本（绝不向工作目录落文件），保存位置由系统对话框确认。
- 变更页工具菜单「应用补丁文件」：选择 format-patch 或 diff 文件后先以 `--numstat` 预览影响（文件数、增删行、二进制文件），确认后才应用到工作区——不直接创建提交，改动在变更页审查后自行提交。
- 补丁文本经 stdin 通道传递，与行级暂存同一套机制；8 MiB / UTF-8 窄通道读写。

## 提交详情增强

- **距标签距离徽标**：提交详情显示「v0.11.0 +4」形式的距最近标签距离（`describe --tags --long`），点击定位到标签提交；标签覆盖的提交只显示标签名。
- **Blame / 文件历史跳转**：点击尚未加载的提交哈希改为 hash 直达（rev-parse + show 现取现跳），不再提示「未加载」。
- **文件历史分页**：文件历史列表支持「加载更早提交」，按窗口递增分页（规避 `--follow` 下 `--skip` 按过滤前提交流计数的偏移问题）。

## 仓库统计

- 「仓库健康度诊断」弹窗改为双 tab：健康诊断 / **仓库统计**。
- 统计页展示对象库四项指标（松散对象数 / 松散体积 / 包内对象数 / 包体积，`count-objects -vH`）与当前分支贡献榜 Top 20（`shortlog -s -n --no-merges`，含占比条）。

## 全局忽略规则

- 忽略规则目的地新增第三档「本机全局规则（core.excludesFile）」：未配置时自动落在 `~/.config/git/ignore` 并代写该配置，路径只来自 git config 或 XDG 默认计算，不接受任意路径。
- 全局规则影响本机所有仓库，界面带醒目警示；预览同时叠加仓库 .gitignore 与 info/exclude 的实际语义。

## 提交备注（git notes）

- 提交详情新增「备注」区块：查看、添加、编辑、删除，空内容即删除；写入走 Git 写队列串行。

## 跨平台终端

- 外部终端支持扩展至全平台：macOS 使用系统 Terminal 在仓库目录开新窗口；Linux 按候选顺序探测常见终端模拟器（gnome-terminal / konsole / xfce4-terminal / alacritty / kitty / wezterm / xterm 兜底），目录以独立参数传递，无 shell 注入面。

## 安全与工程

- `grep`、`describe`、`format-patch`、`shortlog`、`count-objects`、`notes` 六个新 Git 子命令全部进入策略白名单的窄形态校验（如 format-patch 强制 `--stdout`、notes 拒绝 append/copy/merge/prune 与文件面选项），Rust / TS 镜像与开发端点三面测试锁定。
- 新增真仓库测试：代码搜索（字面/正则/pathspec/无命中归一）、补丁导出→预览→应用往返逐字节校验、shortlog/count-objects 统计、describe 解析与文件历史分页。

## 测试

- Rust 测试 65 + 64 → **74 + 73**（默认 / 无 GitHub 两档，clippy 零告警）。
- e2e 浏览器回归 93 → **101**：新增全局搜索交互与暗/亮视觉基线；history 视觉基线随详情徽标与顶栏按钮重建。
- 中英双语、暗色 / 浅色主题下新增界面无混排；真机实测代码搜索、备注写入、统计面板与全局 ignore 往返。

---

Version 0.12.0 fills the remaining desktop Git workflow gaps: a Ctrl+Shift+G global code search overlay (literal or regex, grouped by file, with hit highlighting), commit patch export via `format-patch --stdout` and review-first patch import (`apply --numstat` preview before touching the worktree), the distance-to-tag badge in commit details, blame/file-history jumps for unloaded commits, paged file history (window-growth paging that avoids the `--follow --skip` filtering offset), a repository statistics tab in the health dialog (object store metrics plus a contributor leaderboard), machine-wide global ignore rules backed by `core.excludesFile` with an explicit warning, `git notes` read/write in commit details, and external terminal support on macOS and Linux. Six new git subcommands enter the policy allowlist as narrow fixed shapes with Rust/TS mirror tests. Test base: 74 + 73 Rust (two feature profiles), 101 e2e checks, node suite green.
