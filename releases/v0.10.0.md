# AuuGit v0.10.0 · 审查视图定位与性能

本版聚焦审查视图（变更页差异阅读）的定位效率与滚动稳定：差异区右缘新增修改位置概览标尺、上一处 / 下一处修改导航、完整文件模式自动落位，并修复外部变更周期刷新导致的整文件视图闪断与滚动位置丢失。

## 概览标尺与快速定位

- **概览标尺**：差异视图右缘新增标尺，每段连续修改按内容位置排成红 / 绿双段标记（删除靠左、新增靠右），与滚动条几何对齐——滚动条停在哪里，修改就在哪里；点击任意标记居中跳到对应修改。统一、分栏、完整文件三种视图均可用，标记数量随修改段自适应。
- **上一处 / 下一处修改**：查找框旁新增双箭头按钮，以视口中心所在的修改段为基准前后导航，到末段自动回绕，配合搜索匹配导航使用互不干扰。
- **完整文件自动落位**：进入「完整文件」（或在该模式下切换文件）时自动滚动到第一处修改，免去在长文件里手动翻找；切回「仅变更」同样落到第一处。

## 滚动位置与刷新稳定

- 整文件内容改为**后台校验**：外部变更轮询（约每 10 秒）触发的刷新不再把视图塌缩重建，重读结果与展示内容一致时对视图零影响，读取失败保留旧内容；这一改动同时消除完整文件模式的周期性闪断。
- 同一文件的内容真被外部改动时，差异刷新后**恢复原滚动位置**（换文件或暂存 / 未暂存切换不继承旧位置）。
- 文件列表的审核状态不再随无变化的周期刷新整体重渲，滚动位置、行选择勾选在跨轮询刷新后均保持。

## 依赖升级

- tauri 插件 npm / cargo 配对升级：plugin-shell 2.6.0、plugin-notification 2.8.0、plugin-dialog 2.8.4、plugin-updater 2.14.1（PR #17 / #18），及 lucide-react、eslint、globals 等 7 项 npm 小版本。crate 与 npm 包同 minor 对齐，避免 tauri 版本一致性校验失败。

## 测试

- 单元测试 690 → **693**：新增概览标尺修改段计算（统一 / 分栏口径、块头与上下文切断、分栏补位行）与整文件内容一致性判定用例。
- e2e 浏览器回归 **93** 项全绿；`tsc`、`eslint` 全绿。
- Rust 测试 **64 + 63**（默认 / 无 GitHub 两档，随 CI 通过）。

## 验证

- 900 行真实仓库实测：静置 93 秒跨 9 个轮询 tick 滚动位置零漂移、内容高度无抖动；外部编辑后新修改标记位置准确（行 850/900 → 94.2%）；4 段修改循环跳转回绕正常。
- 中英双语、暗色 / 浅色主题下标尺、按钮与提示文案无混排。
- master「Validate changes」三 job（validate / 前端跨平台 / Chromium 视觉）全绿；`check:release` 版本一致性通过。

Headline changes of v0.10.0: the review diff view gains an overview ruler — every contiguous block of added/removed lines is drawn as paired green/red marks on the right edge, aligned with scrollbar geometry and clickable to jump straight to the change. Prev/next change buttons next to the diff search box navigate between blocks with wrap-around, and entering whole-file view auto-scrolls to the first change. Periodic background refreshes no longer collapse and rebuild the whole-file view (stale-while-revalidate with identity-preserving re-reads), the scroll position is restored when the same file is genuinely re-read, and no-op refreshes stop re-rendering the review file list. Tauri plugin crates and npm packages were bumped in lockstep (shell 2.6.0, notification 2.8.0, dialog 2.8.4, updater 2.14.1). Test base: 693 node + 64/63 Rust + 93 e2e checks, all green.
