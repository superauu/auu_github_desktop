# AuuGit v0.3.12

本次更新完善 GitHub Actions 表单、Git 操作反馈、异常恢复和应用更新体验。

## 新增与改进

- **工作流参数表单**：从所选分支读取 `workflow_dispatch` 定义，显示必填项、默认值、选项和布尔值；支持数字及环境名称输入。切换分支会重新加载，加载失败可重试。
- **界面异常恢复**：主视图出错时显示重试、诊断信息复制和窗口重新加载入口，便于恢复和排查。
- **Git 任务反馈**：状态栏显示操作名称、耗时与排队数量。可取消尚未执行的排队任务，正在执行的操作继续完成。
- **最近操作**：保留本次会话最近 100 条 Git 写操作和通知，支持失败筛选、复制详情、重试失败的获取操作，以及打开对应仓库的恢复中心。
- **后台刷新优化**：空闲时逐步降低刷新频率，合并窗口聚焦触发的刷新；相同差异复用解析结果，同时保留对连续编辑的检测。
- **更新流程优化**：增加版本说明、下载进度和“稍后处理”。下载完成后，经用户确认才安装并重启；所有仓库的 Git 任务未结束时阻止安装。

## 下载说明

- Windows x64 安装版：选择 `AuuGit_0.3.12_x64-setup.exe` 或 MSI 安装包。
- 独立可执行文件：选择 `auugit.exe`。
- 安装更新前，请先保存正在编辑的内容。

## Validation

- Windows desktop build and signed update assets are generated by the release workflow.
