# AuuGit v0.4.2 · 安全加固与稳定性修复

## Git 执行安全

- 重构 Git 参数过滤策略：按命令声明选项取值语义，封堵通过取值选项走私 `--output` 等危险参数的通道（该通道可导致任意路径文件写入）。
- 封堵 `diff --no-index`、`hash-object -w`、`commit -F` 等"让 Git 自行读盘"的选项被用于读取仓库外任意文件的路径，路径类参数统一纳入仓库授权边界校验。
- 本地路径远程仓库（如磁盘上的裸仓库备份）的推送/拉取/抓取在授权目录内正常工作，授权范围之外一律拒绝。
- `git init`、`git worktree move` 的目标目录纳入授权校验；AI 请求头经显式校验，非法字符不再可能导致命令层崩溃。
- 系统浏览器跳转收紧至 github.com 域名；Git 子进程输入限长 8 MiB 并增加并发上限，防资源耗尽。

## 服务层修复

- 新建分支、新建标签入口增加名称校验：以 `-` 开头或形如选项的输入会被拒绝，杜绝"新建"动作反向删除分支或标签的注入可能；revert / cherry-pick / reset 的哈希参数先解析校验再执行。
- 解决混合换行符（CRLF/LF 并存）冲突文件时，仅重写目标冲突块，不再把整个文件的行尾归一化。
- 仓库状态诊断不再依赖本地化文案，中文等语言环境下检测不再失效；复制状态（C）不再被误标为冲突。
- GitHub 设备码登录对瞬时网络错误自动重试，仅终态错误终止流程；全部 GitHub API 请求补齐超时；PR 列表分页加上限。
- AI 提交信息与 PR 生成路径与批量规划一致，对 diff 内容加定界与"数据非指令"防护；错误信息截断防止超长响应进入提示。

## 界面与体验

- 标签行内删除按钮增加确认弹窗，与右键菜单路径行为一致。
- 顶部栏、左侧导航、右侧提交面板各自包覆错误边界，局部渲染异常不再扩散为整窗错误页。
- 输入框内可呼出命令面板（Ctrl+K），弹窗内可呼出 Git 控制台（Ctrl+`）；侧栏搜索快捷键增加弹窗守卫。
- 大文件冲突解决器对普通段落启用行级虚拟化，数万行冲突文件不再卡顿。
- 提交历史视图对旧版持久化数据做防御合并，不再因字段缺失崩溃；会话状态持久化增加版本迁移与容量上限。
- 修复标签删除缺少确认、布局约束回归、监听器泄漏、防抖缺失等十余处问题；补齐中英文案二十余键，双语界面无混排。

## 工程与发布

- 发布流水线在打标签构建前强制执行 lint、clippy 与后端测试；CI 新增 Ubuntu 前端跨平台验证任务。
- 新增词典完整性测试：键奇偶、占位符一致性与静态调用扫描三重门禁，漏键在测试期拦截。
- vite.config 与构建脚本纳入 TypeScript 类型检查；启用 no-unused-vars 规则。

## 验证

- 223 项前端回归测试（含分支/标签校验拒绝、混合行尾、本地远程传输授权、竞态注入），tsc 与 eslint 零告警。
- Git 参数策略 Rust 单元测试与 TS 镜像端到端用例同步覆盖，dev server 冒烟验证放行与拒绝矩阵。
- 中英双语界面实机截图验证，无键名泄漏与布局回归。
- Windows 发布流程生成 NSIS、MSI、便携程序及带签名的自动更新元数据。

---

This release hardens the Git execution policy against option-smuggling and out-of-repository file read/write vectors, gates local-path remotes behind repository authorization, validates branch/tag/revert inputs against injection, resolves mixed-EOL conflict rewrites, and adds OAuth polling resilience, GitHub API timeouts, per-pane error boundaries, virtualized conflict resolution, and a dictionary-integrity test gate. The release pipeline now enforces lint, clippy and backend tests before building tagged versions.
