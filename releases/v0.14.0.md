# AuuGit v0.14.0 · Git 能力面收口

本版补齐一批桌面 Git 工作流的能力细口：未跟踪文件删除、worktree 删除与清理、压缩合并、混合重置、贮藏建分支、浅克隆与远端分支预览，以及仓库维护（gc）、完整性检查（fsck）与提交归档导出（zip）。全部新 Git 形态走双向窄校验，Rust / TS 镜像与真仓库测试三面锁定。

## 变更页

- **未跟踪文件可删除**：右键菜单新增「删除未跟踪文件」，走 `clean -f` 单文件窄形态（不可恢复的二次确认）；策略拒绝目录面 `-d`、忽略文件面 `-x/-X`、交互 `-i`、干跑 `-n` 等一切扩展（fail closed）。

## worktree 管理

- **worktree 可删除**：列表行内新增删除按钮——注册校验（防任意目录删除）、主工作树与锁定态拒绝、越权目录走授权确认三重防线；含未提交改动的 worktree 由 git 拒绝删除。
- **失联条目可清理**：目录已被外部删除的 prunable 条目提供「清理」按钮（`worktree prune`）。

## 合并 / 重置 / 贮藏

- **压缩合并（--squash）**：分支拖放合并弹窗新增选项——不产生合并提交，改动以暂存态进入目标分支（安全预览同步说明压缩语义，squash 与 no-ff 互斥，提交说明可预填）。
- **混合重置**：提交历史右键新增「混合重置到此提交」——HEAD 与暂存区回退、工作区文件保留（改动退回未暂存）。
- **从贮藏建分支**：侧栏贮藏右键新增入口，输入新分支名后在新分支上恢复贮藏（git 标准语义：成功即 drop 原贮藏条目，内容已转移到新分支）。

## 克隆

- **浅克隆深度（--depth）**：克隆对话框新增深度输入（留空 = 完整克隆，1–10000 校验），大仓库快速上手、后续可 fetch 补全。
- **远端分支预览**：URL 输入旁「列出分支」——`ls-remote` 读取远端分支名（tag 剔除）以输入联想填充，本地路径目标的传输授权与 push/fetch 同构；GitQueue 归只读可并发。

## 仓库健康

- **执行维护（git gc）**：统计 tab 新增维护动作——确认后打包松散对象并刷新统计（真仓库验证松散对象归零）；策略只放行裸调用，`--aggressive` / `--prune=now` / `--auto` 等一律拒绝。
- **完整性检查（fsck）**：健康诊断新增检查按钮——对象库损坏时展示报告并醒目警示先备份；策略只放行裸调用。
- **导出归档（zip）**：提交右键新增「导出归档」——`git archive --format=zip` 的二进制产物在 Rust 侧直写用户保存对话框确认的路径（不经前端 UTF-8 字符串通道，缓冲上限 1 GiB）；策略只放行 `--format=<zip|tar.gz> <tree-ish>` 两参形态，`-o` / `--output` / 压缩等级等落盘面与走私形态全部拒绝。

## 安全与工程

- 五个新 Git 子命令（`clean` / `gc` / `fsck` / `ls-remote` / `archive`）全部进入策略白名单的窄形态校验，Rust / TS 镜像与 dev 端点三面测试锁定；`ls-remote` 的本地路径传输授权与 push/fetch/pull 同构（Rust transport_grant 与 dev 桥接一致）。
- worktree 删除的调用层三重防线（注册校验 / 主树与锁定拒绝 / 授权确认）与归档导出的扩展名一致性校验各有 Rust 纯函数测试。

## 测试

- node 全量 **737** 项（新增 git 能力面真仓库套件：删除/还原/保留三态、worktree 四态、squash 语义、混合重置、贮藏建分支、file:// 浅克隆提交数、远端分支过滤、gc 松散对象归零）、Rust 测试 **78** + clippy `-D warnings`、e2e integrations **3** 全绿。
- i18n 中英双语零混排（新增键全走 t()，完整性门禁通过）。

---

Version 0.14.0 closes the remaining desktop Git workflow gaps: untracked-file deletion via a narrowly validated `clean -f` (directory/ignored/interactive/dry-run forms rejected), linked-worktree removal with caller-side defenses (registered-path check, main-tree and locked refusal, authorization prompt) plus `worktree prune` for stale entries, squash merge in the drag-and-drop merge dialog (staged changes, no merge commit, preview adapted, exclusive with --no-ff), mixed reset in the commit context menu (HEAD and index move back, worktree stays), create-branch-from-stash in the sidebar (git's drop-on-success semantics locked by tests), shallow clone depth with validation, and pre-clone remote branch preview via `ls-remote` with transport authorization mirroring push/fetch. Repository health gains a `git gc` maintenance action and an `fsck` integrity check (both bare-form only, fail closed), and commits export as zip archives through a Rust-side direct-write channel (`git archive` bypassing the UTF-8 string pipe, 1 GiB buffer cap, extension-consistency check). Five new git subcommands enter the policy allowlist as narrow shapes locked by Rust/TS mirror tests and a real-repository suite. Test base: 737 node, 78 Rust, clippy clean, 3 e2e integration specs.
