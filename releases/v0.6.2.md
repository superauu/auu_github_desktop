# AuuGit v0.6.2 · 在工作区完成代码审核

## 更顺手的提交前审核

- **审核前移到工作区变更**：按文件或代码块审核，再暂存和提交；移除提交后的「阶段复核」入口，减少重复操作。
- **清楚看到待审文件**：文件列表显示已审核、待审核、部分代码块进度及待解决意见数；支持搜索文件名、当前路径和重命名前路径，以及按审核状态筛选。
- **连续与批量审核**：支持「通过并继续」「下一个待审核」「全部审核通过」。筛选后的审核、暂存、取消暂存只处理列表显示项。批量审核显示读取进度，可取消或仅重试读取失败文件；取消不新增通过记录。
- **提醒可以关闭**：提交前的未审核提醒默认开启，可返回审核或继续提交，也可在 Git 设置中关闭。

## 审核意见与 AI 修复报告

- 工作区可直接生成、预览和复制 AI 修复报告，包含记录意见时的原始差异上下文。
- 意见支持编辑、标记已解决、删除与撤销；Ctrl/⌘+Enter 保存，当前会话保留输入草稿。
- 「定位代码」选择对应的暂存或未暂存版本，滚动并高亮原代码块；原代码块变化时提示核对。编辑检测到并发修改时保留草稿，不覆盖新内容。
- 进行中的审核在本机临时保存，重开应用可继续。文件离开工作区变更后自动清理已完成记录；未解决意见及同一文件剩余未提交修改继续保留。已提交文件的未解决意见仍可在「管理意见」中处理。

## 差异视图与历史工具

- 修复自动换行不生效、横向滚动后红绿背景丢失以及代码块审核工具条位置异常。
- 修复文件列表悬停时高度变化；未变更内容的后台核对保持审核标记、右侧差异、选区和滚动位置稳定。
- 长文件列表与长差异按可见区域渲染，减少大量变更时的界面负担。
- 二分查找和整理提交收进「提交历史 → 更多工具」。二分操作保护暂存、未暂存和未跟踪修改，支持关闭后继续已有会话，并在完成后还原原检出位置。

## 使用说明

推荐流程：工作区审核 → 记录问题或复制 AI 修复报告 → 修复并解决意见 → 审核通过 → 暂存 → 提交。

使用指南：[代码审核使用指南](https://github.com/superauu/auu_github_desktop/blob/v0.6.2/docs/review-guide.md)。

Windows 用户可使用应用内自动更新；macOS 和 Linux 用户请下载对应架构安装包。

---

This release moves code review into working changes before staging and committing. It adds searchable review filters, scoped bulk approvals with progress/cancel/retry, editable findings with precise code navigation, and AI fix reports with original diff context. Completed records are cleared automatically while unresolved findings and ongoing work are retained. It also fixes wrapping, horizontal diff styling, hover layout changes and periodic refresh flicker, and strengthens protections around Git bisect sessions.
