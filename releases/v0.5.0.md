# AuuGit v0.5.0 · 仓库工具、多平台托管与三平台构建

## 仓库工具（子模块 / Git LFS / 提交签名）

变更面板新增"仓库工具"入口，三个仓库级工具统一在一个弹窗内：

- **子模块管理**：列表展示状态（已初始化 / 有改动 / 冲突 / 未初始化）、当前提交与 describe；添加子模块（URL / 已授权本地路径 / 可选分支）；递归初始化更新、同步远程地址、取消初始化（带确认）；`.gitmodules` 变更提交提示。
- **Git LFS**：自动检测 git-lfs（未安装时给出安装指引而非报错）；仓库级过滤开关（仅写本仓库配置与 hooks，不碰全局）；跟踪模式管理（写入 .gitattributes）；LFS 文件列表与一键拉取。
- **SSH 提交签名**：一键启用本仓库 SSH 签名（`gpg.format=ssh` + `user.signingkey` + `commit.gpgsign`）；列举 `~/.ssh` 公钥（含指纹）、生成无口令 ed25519 密钥对、非桌面环境降级为手动路径；公钥一键复制便于在托管平台登记验证。

安全边界：策略层新增子命令门——`git submodule foreach`（执行任意命令）、`git lfs migrate`（重写历史）永久封禁；`git lfs install` 仅允许 `--local`；签名配置写白名单只放行四个键，`gpg.program` / `gpg.ssh.program` 等任意可执行文件配置面永不放行；SSH 私钥内容永不出后端。

## 多平台托管（GitLab / Gitea）

- 新增"GitLab / Gitea"视图（侧边栏入口，Alt+5）：打开仓库后自动识别 origin 远程（gitlab.com 或已连接的自建服务器域名命中即进入）。
- PAT 连接：令牌保存在系统凭据管理器（与 GitHub 凭据同构的独立槽位），支持 gitlab.com 与自建 GitLab CE / 极狐、Gitea / Forgejo。
- 能力面：打开的合并请求列表（状态徽标、作者、分支）、详情弹窗（描述、评论时间线、源分支流水线 / CI 状态、浏览器跳转）。
- GitHub 既有深度界面（PR 评审、Actions、通知等）完全不受影响。

## 三平台构建

- 发布产物从 Windows 扩展到三平台：Windows（NSIS/MSI/便携版，不变）、macOS（Apple Silicon 与 Intel 双架构 DMG）、Linux（AppImage / deb / rpm）。
- 每个平台在发布前独立通过 clippy 与 Rust 测试（平台首编门）。
- macOS/Linux 暂为手动下载安装（自动更新元数据暂只含 Windows，跨平台更新合并待后续版本）；macOS 构建未做 Apple 开发者签名，首次打开需在系统设置中允许。

## 修复

- 账号菜单"添加账号 / 管理账号"在桌面版点击无反应：菜单 select 与弹窗DismissibleLayer 的时序竞态导致弹窗闪关，现延迟到菜单卸载后再打开；"管理账号"同时改为直达设置的 GitHub 账户分区（原先误开外观分区）。

## 验证

- 前端回归测试扩至 313 项（新增仓库工具策略、子模块/LFS/签名、多平台服务映射专项），tsc 与 eslint 零告警。
- 中英双语实机验证：仓库工具三个标签页、GitLab 视图的识别/错误/连接路径、账号菜单两项的真实指针点击。
- 三平台发布工作流：Windows 创建 Release 与更新元数据，macOS/Linux 产物挂载同一 Release。

---

This release ships repository tools (submodule management, Git LFS with repo-scoped filters and track management, and one-click SSH commit signing with in-app key generation), multi-forge hosting (GitLab and Gitea/Gitea/Forgejo with PAT auth, auto-detected remotes, merge-request browsing and pipeline status), and expands release builds from Windows-only to Windows, macOS (Apple Silicon + Intel) and Linux (AppImage/deb/rpm). Policy hardening permanently blocks `submodule foreach` and `lfs migrate`, restricts `lfs install` to `--local`, and whitelists exactly four signing config keys. Test coverage grows to 313 behavioral cases.
