# AuuGit v0.4.0 · 全新玻璃工作区

这是一次界面与窗口外壳升级：黑灰玻璃工作区、自定义标题栏和贴底状态栏统一为完整的桌面界面，同时收录自 v0.3.16 以来的 AI 规划、推送状态和仓库安全改进。

## 全新桌面界面

- **自定义标题栏**：仓库标签、分支标识、登录、主题与设置集成在窗口顶部，加入最小化、最大化／还原和关闭按钮；空白区域支持拖动和双击最大化，交互控件保持独立可点击。
- **贴底状态栏**：状态栏铺满窗口底边，与标题栏保持一致的配色，保留仓库、分支、领先／落后数量、Git 状态、更新提示与最近操作入口。
- **中性玻璃主题**：导航、工具栏、工作区和弹窗采用黑灰色磨砂效果；代码区域保持清晰。优化浅色主题的按钮边框与文字对比度，并支持减少透明度设置。
- **统一控件**：获取更新、拉取、推送按钮保持一致；仓库和分支选择器同高，仓库标签页增加留白、柔和的选中标识和独立分支标识。
- **布局修复**：错误提示可关闭并保留提交草稿；展开技术详情或提交文件列表时，底部提交操作仍保持可见。Git 控制台配色跟随深浅主题。

## Git 与 AI 工作流

- 恢复尚未推送的提交数量，有待推送提交时突出显示推送按钮。
- 优化 AI 规划的变更收集，显示准备和等待阶段，支持取消并设置请求超时。
- 桌面版通过原生命令打开系统终端，失败时给出提示；网页预览中的原生窗口控制及外部终端入口保持禁用。

## 仓库与本地访问保护

- 新增目录授权与撤销入口，限制 Git 操作和文件读写范围，保持克隆、初始化及工作树功能可用。
- 补齐 clone/init 配置短选项绕过及合并策略过滤，检查自定义 Git 程序来源，并限制目录浏览接口范围。
- 图片读取使用受控 Git 执行流程，文本读取设置大小上限，文件保存使用原子替换。
- 校验 OAuth 验证网址，打包本地字体并收紧生产内容安全策略。

## 验证与说明

- 196 项自动化回归通过，覆盖原生窗口命令调用、重复点击防护、最大化与焦点状态、拖动区域和交互控件区分，以及状态栏操作入口。
- 深浅主题及 900 × 600 最小窗口尺寸的网页布局已验证。
- 发布前执行版本一致性、代码规范、前端生产构建和 Windows Rust 后端检查；发布流程生成 Windows 安装包及自动更新签名。
- 本次自定义标题栏未额外实现 Windows 11 最大化按钮悬停时的分屏布局菜单。跨屏缩放和原生窗口交互仍需更多桌面实测反馈。
