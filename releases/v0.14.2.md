# AuuGit v0.14.2 · 工程化夯实

本版完成一批代码库质量收口：JSX 可访问性静态防线接入、i18n 插值统一收敛、视觉基线管线归一。功能零变化，防御面与可维护性上一台阶。

## 可访问性防线（jsx-a11y 接入）

- `eslint-plugin-jsx-a11y` recommended 全量接入，防止新代码引入可访问性回退。
- 四条规则按接入审计的量化结论调档：交互三规则（click-events / static-element / noninteractive-element-interactions）对 `keyboardRowProps` 展开的行内键盘处理存在盲视（审计 24 处误报），且弹层包装、终端聚焦代理、diff 标尺等指针面按设计即指针交互（键盘路径由对话框 Escape/焦点约定承担）；`no-autofocus` 放行对话框打开即聚焦的既定 UX 约定；`no-noninteractive-tabindex` 放行键盘滚动区（region）/ 分隔柄（separator）/ 键盘行（listitem）角色；`label-has-associated-control` 深度调至 4 层以准确扫描嵌套文本。
- 接入时修复存量真实缺口：三处键盘可达滚动区补 region 标注（diff 预览 / hunk 原文 / markdown 表格）、上下文菜单容器焦点（tabIndex）、CI 运行列表的 button/listitem 角色错配、两处表单 label 显式关联。

## i18n 插值统一（tf/tfNow）

- 全仓 **203 处** `t(key).replace('{x}', v)` 迁移到 `tf(key, { x: v })` / `tfNow(...)`：底层 `interpolate` 用函数式替换，免疫字符串 replacement 的 `$&` / `$'` 等特殊序列污染（值含 `$` 时被错误展开）。
- 其中 5 处为**真修**：AI 修复分支名模板（用户可编辑，标题含 `$` 会腐化分支名）与 AI 错误体消息此前即存在该缺陷。
- 纯函数模块（报告构建 / 文件状态标签）的翻译注入签名放宽为 `(key, vars?)`，插值能力随注入传递；测试桩同步补齐 tfNow/tf。

## 视觉基线管线归一

- 退役 CUA 手动审查套（6 张 JPEG 基线 + Python 比较器 + actual/diffs 临时目录）——其六个 history 场景早已由 `e2e/visual.spec.ts` 的 `toHaveScreenshot` PNG 自动管线以同一夹具、同一视口全覆盖。
- 视觉回归收敛为单管线：cases.json（场景定义）→ Playwright 自动比较 → `baselines/playwright-<platform>/` 审查基线；README 同步架构说明。

## 评估后不做（决策记录）

- **noUncheckedIndexedAccess 全局开关**：启用试验暴露 404 处，其中安全策略镜像（scripts/git-policy.ts 的 argv 窄形态校验器）占大头——改造等价于安全层全量重写，回归风险与收益不成比例，评估后不开（解析器两处顺手补了诚实守卫）。渐进开启可在后续按模块推进。
