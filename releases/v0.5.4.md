# AuuGit v0.5.4 · 依赖与构建链路大版本升级

## 工程升级

- **构建工具链**：Vite 8（Rolldown 内核）——生产构建从 7.8s 提速到 2.1s，主 JavaScript 分包从 416KB 减至 391KB（gzip 102KB）；恢复中心弹窗拆为独立按需分块。
- **运行时框架**：React 19、Tailwind CSS 4（主题配置迁移为 CSS-first，删除独立 config 文件）。全部 322 项回归测试与暗色/浅色双主题视觉冒烟在新栈下通过。
- **桌面端**：Tauri 插件对齐升级——自动更新器 2.11→2.14、shell、dialog、fs；Tauri 核心保持 2.12 线不变。依赖审计漏洞清零（含 Vite 5 内嵌 esbuild 的开发服务器漏洞）。
- 小版本依赖同步：Radix UI 全家桶、lucide-react 1.x（品牌图标已本地化补齐）、esbuild、TypeScript 工具链等。

## 行为说明

- 本版本为维护版本：**功能与界面行为与 v0.5.3 完全一致**，无新功能、无界面改动；升级内容为构建性能、包体积与依赖安全。
- 自动更新链路已按发布例程重新验证（updater 插件升级后的签名安装与 latest.json 清单检查）。

## 验证

- 322 项前端回归测试全绿，tsc 与 eslint 零告警，`npm audit` 零漏洞。
- Rust 侧 cargo test 与 clippy（-D warnings）通过；发布版真机启动冒烟通过。
- 发布例程五步全过：release 构建 → 真 exe 启动 45s 观察 → 更新链路检查 → 版本一致性 → 打 tag。
