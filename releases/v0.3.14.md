# AuuGit v0.3.14

本次更新新增 AI 规划多个提交，并完善多远程操作、跨仓库 PR 和整体界面体验。

## 新增与改进

- **AI 规划全部变更**：分析已暂存、未暂存及新文件，建议提交数量、文件分组和顺序，为每个提交生成标题、详细说明及分组理由。确认前可编辑说明、移动文件、调整顺序或合并分组；确认后批量提交，或选择远程目标，在全部提交完成后推送一次。
- **执行保护与失败恢复**：分析不会修改暂存区或创建提交，原有提交草稿保持不变。文件、暂存区或分支发生变化时阻止旧计划执行；中途失败保留已完成的提交并报告结果，推送失败只重试推送。AI 请求失败或返回无效分组时停止分析，可重试或继续普通提交。
- **远程操作**：改进远程目标选择、推送结果反馈与默认偏好保存提示；完善远程分支删除、远程获取和 GitHub 协作仓库的配置体验。
- **PR 与 Actions**：修复跨 fork PR 的来源分支定位和切换仓库后的目标分支加载；隔离过期请求和搜索状态，完善工作流运行状态与加载反馈。
- **界面与键盘操作**：优化侧栏、提交面板宽度与响应式布局，完善列表键盘导航、弹出层焦点恢复、表单标签、主题颜色和错误提示。

## 使用说明

- AI 规划需要配置 AI 接口、密钥及模型。当前按完整文件拆分；部分暂存文件会使用完整工作区版本，请确认预览后执行。
- AI 可能生成不合理的分组或说明，请在确认前检查。当前最多分析 200 个变更文件并生成 12 个提交，不支持拆分同一文件内的不同修改或处理已变更的子模块。
- Windows x64：选择 `AuuGit_0.3.14_x64-setup.exe`、MSI 安装包或独立可执行文件 `auugit.exe`。安装更新前请保存正在编辑的内容。

## Validation

- 168 automated regression tests, including real Git repositories for batch commits, stale-plan rejection, hook failures, index restoration, and push retry behavior.
- Release version consistency and TypeScript / frontend production build checks.
- Windows desktop compilation, signed installers, and automatic-update metadata are verified by the release workflow before publication.

---

This release adds AI-assisted planning of multiple commits with editable file groups and commit messages, confirmation before execution, stale-plan protection, partial-failure reporting, and push-only retries. It also improves remote operations, cross-fork pull requests, Actions status, keyboard navigation, accessibility, and responsive layouts. AI planning requires a configured provider and groups whole files; partially staged files use their full working-tree contents.
