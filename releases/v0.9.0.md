# AuuGit v0.9.0 · Linear 任务来源与 Issues 工作区

## 新功能：Linear 任务来源（首个独立任务插件）

- Linear 集成完整落地：GraphQL 客户端（api.linear.app，经统一 Provider 传输）+ PKCE OAuth 浏览器授权（免 client_secret，本机 `127.0.0.1:53862` 回跳）+ 个人 API Key 兜底。Windows 下修复了非阻塞套接字继承导致的 10035 与浏览器探测连接误杀。
- 连接账号即启用：设置 → 集成新增「任务追踪」分组，已连接行直接展示；令牌只存操作系统凭据管理器，OAuth 刷新令牌轮转先落盘再继续。启动时自动校验连接健康态，重启后不再残留「未验证」。
- Issues 页的来源成为过滤维度：仓库 Issue 与 Linear 任务进入同一列表，可切换「全部来源 / 仓库 / Linear」；没有仓库托管账号也能直接用 Linear 工作。
- 任务引用贯通：`ENG-123` 作为展示键与外链（`linear.app/issue/ENG-123`），创建分支默认名带 identifier，PR 关联使用 `Refs ENG-123`（不伪造 Closes 语义）；能力按 Linear manifest 判定——编辑、评论、关闭为已完成可用，未声明能力（如关闭为不计划处理）给出禁用原因。
- 通用 OAuth 回跳通道抽出（Rust 命令 + 前端 `services/oauth/loopback`），后续平台可复用。授权完成页跟随界面语言与平台名，成功 / 失败 / 无效三种版式；页面 CSP 收紧到 `default-src 'none'`，provider 名与错误码一律转义。

## 新功能：Issues 工作区重设计

- 列表 / 详情全宽双栏：列表行改为紧凑单按钮行（状态图标、标签、评论数、负责人头像、更新时间），来源过滤器收进工具栏；列宽可拖拽，分隔条支持方向键与 Home / End 调整、双击复位。
- 分页浏览：列表底部「加载更多」按来源独立追加，失败页原位重试；切换筛选回到顶部，显示已加载数量与 1000 条搜索上限提示。
- 筛选面板：状态、来源、标签、负责人收进可折叠区域，提供一键清除筛选；空结果给出下一步提示。
- Markdown 渲染：描述、评论与编辑预览统一走 Markdown（标题、列表、代码块、表格、任务清单、图片）；原始 HTML 一律丢弃，`javascript:` 等危险链接拒绝渲染，外链经系统浏览器打开。讨论区进入主阅读列，属性面板收在右栏。

## 其他改进

- 差异视图：代码块头显示所属方法 / 函数（JS/TS、Python、Go、Rust 等），新增「完整文件」只读视图（补齐块间上下文、保留两侧行号；完整文件模式隐藏块级暂存入口，超大文件自动回退仅变更）。
- 工作区变更列表末列动作轨道固定，待审核徽标不再随悬停跳动；冲突徽标优化。
- 插件装配层支持独立 task / ci 装配档，`AUUGIT_PLUGINS` 可裁剪；连接形态词汇预留 task-account / ci-server。

## 已知限制

- Linear 新建 Issue 使用默认团队（暂无团队选择器）；Linear 没有时间线实体，详情不显示活动时间线；Issue 正文中的 Linear 链接尚未自动解析为关联任务。
- Linear OAuth 依赖平台应用登记的回跳地址 `http://127.0.0.1:53862/callback`；端口被占用时会明确报错而不是静默失败。
- 本版验收基于夹具与自动化用例；真实 Linear 账号的首次浏览器授权仍建议用户自行走一遍确认。

- Rust 测试 **64 + 63**（默认 / 无 GitHub 两档）：新增授权完成页语言、HTML 转义与 CSP 断言。

- `tsc`、`eslint`、`check:plugins`、`check:release` 全绿；两种 feature 档 clippy（CI 同款 `-D warnings`）零告警。

## 验证

- 690 项 node 测试、64 + 63 项 Rust 测试、75 项 e2e 全绿；`check:release` 版本一致性通过（应用 0.9.0 / Tauri 2 线）。
- 视觉基线已按新列表与详情布局重建，暗色 1440×900、浅色 750×600 视口通过。
- Linear 流程（浏览器授权 → 回跳完成页 → 令牌入 keyring → Issues 列表 / 详情 / 评论 / 关闭）由夹具 e2e 与单测覆盖。

---

Headline changes of v0.9.0: Linear arrives as the first standalone task plugin — GraphQL client, PKCE browser authorization with local loopback, API-key fallback, and an Issues workspace where repository issues and Linear tasks share one filterable inbox with `ENG-123` references wired into branch names, external links and PR links. The Issues page is redesigned as a desktop-style list/detail split: compact rows, drag-and-keyboard resizable divider, load-more pagination with in-place retry, a collapsible filter panel, and Markdown rendering (with raw HTML and dangerous URL schemes rejected) for descriptions, comments and previews. OAuth completion pages now follow the selected UI language and provider name with success / error / invalid layouts. Also included: enclosing-method labels and a read-only whole-file diff view, stable action rails in working changes, and build-time task/ci plugin profiles. Test base grows to 690 node + 64/63 Rust (two feature profiles) + 75 e2e checks, all green.
