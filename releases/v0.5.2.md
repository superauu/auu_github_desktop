# AuuGit v0.5.2 · 账号菜单真机修复

## 修复

- 账号菜单"添加账号 / 管理账号 / 切换账号"在桌面版真实点击无反应（v0.5.0/v0.5.1 的延迟方案未能根治）：通过在你机器上挂 WebView2 远程调试、以真实点击逐帧取证，定位到根因——账号菜单打开后 Radix 内部出现每帧一次的焦点争夺振荡，真实 pointerdown 打进振荡后 4ms 内焦点被夺走、菜单立即自行关闭，鼠标松开时"选择"事件永远无法落在菜单项上。现已把菜单动作直接绑定到 pointerdown 同步执行（此刻事件必达），select 路径保留兜底，全部动作幂等。

## 验证

- 313 项前端回归测试全绿，tsc 与 eslint 零告警。
- 真机事件时间线取证：同一次实验中"更多仓库操作"菜单（新建分支弹窗/刷新）真实点击均正常，佐证为账号菜单独有问题。

---

Fixes the account-menu dead click on desktop by binding menu actions to pointerdown directly: on-device WebView2 tracing showed a per-frame focus oscillation inside the account menu, where a real pointerdown causes focus to leave the item within 4ms and the menu closes itself before the release can produce a select event. All actions are idempotent, so the select path remains as a fallback.
