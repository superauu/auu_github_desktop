# AuuGit v0.4.4 · 品牌确立与交互稳健性

## 品牌与身份

- 启用 AuuGit 自有 OAuth App：设备授权登录不再借用 GitHub CLI 的 Client ID，授权页将显示 AuuGit 而非 GitHub CLI，授权流程本身不变；已登录用户无需重新登录。
- 全新应用图标：按"纯青渐变"品牌规范重制 Logo（炭灰底、霓虹青→深青纵向渐变的提交图意象），并重建全套 52 个平台图标（Windows ICO、macOS ICNS、Android/iOS 各分辨率、商店徽标）。
- 应用内品牌展示收尾：Header 与欢迎页的 Logo 展示简化统一，图标生成脚本与品牌设计档案入库。

## 界面纪律

- 色板纪律：清除残留的 indigo 底色、蓝紫辉光与硬编码颜色，语义色全部走设计 token。
- 动效纪律：全局清除 `transition-all` 改为显式属性列举，欢迎页下划线动画改用 `transform: scaleX`（避免布局抖动），消除无关属性的意外过渡。
- 无障碍补全：图标按钮补齐 `aria-label`，PAT 输入框与标签建立关联，密码框 `autocomplete=off`，残留硬编码文案全部接入双语 t()。
- 细节修正：设置页"已连接"徽标字号对齐全库规格（10px），状态栏改用单轴裁切消除隐患，登录方式 tab 图标贴边问题修复。

## 交互稳健性

- fetch / pull / push 远程操作防重入：互斥锁 + 按钮 spinner + 禁用态，杜绝连点导致的重叠网络操作。
- 暂存/取消暂存批量操作防重入：`runGitAction` 互斥守护，避免并发撞 git index 锁。
- 取消进行中的 CI run 增加确认对话框（双语），补齐破坏性操作确认链。
- AI 批量提交/拆分提交的分组列表改用稳定 id 作为 key：分组移动、合并、重命名后输入状态不再错绑。
- 分组重命名输入框移除裸 `focus:outline-none`，交还全局键盘焦点环。

## 验证

- 前端回归测试全绿，tsc 与 eslint 零告警；GitHub Actions（Windows lint/clippy/cargo test、Ubuntu 前端）全绿。
- 中英双语实机验证：登录页、设置页、Header 品牌区、状态栏与各确认对话框。
- Windows 发布流程生成 NSIS、MSI、便携程序及带签名的自动更新元数据。

---

This release ships AuuGit's own registered OAuth App (replacing the borrowed GitHub CLI client ID), a fully redesigned monochrome-cyan logo with all 52 platform icons rebuilt, color-token and motion discipline sweeps across the UI, accessibility completions (aria-labels, label associations, bilingual copy), and interaction hardening: re-entrancy locks for fetch/pull/push and staging, a confirm dialog for canceling CI runs, stable keys in AI commit grouping, and keyboard focus-ring restoration.
