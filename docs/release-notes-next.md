# v0.6.2 发布验收记录

整理日期：2026-10-28。应用版本为 0.6.2，面向用户的更新说明见 [v0.6.2](../releases/v0.6.2.md)。

## 工作区审核

- 在工作区按文件或代码块审核，支持「通过并继续」「下一个待审核」和「全部审核通过」。
- 审核意见支持会话草稿、Ctrl/⌘+Enter 保存、标记已解决以及删除撤销。
- 增加文件名及路径搜索、审核状态筛选；筛选后的审核、暂存、取消暂存只处理显示项。
- 意见可编辑并定位到对应暂存或未暂存版本的代码块；代码变化后提示核对，保留原始上下文。
- 批量审核显示进度，支持取消及失败文件重试；取消不新增通过记录。
- AI 修复报告默认只包含当前变更中的待解决意见；可管理已提交文件的历史意见。
- 进行中的审核在本机临时保存，文件离开工作区变更后自动清理已完成记录，未解决意见及同文件剩余工作继续保留。不增加备份功能。
- 提交前提醒默认开启，可继续提交，也可关闭提醒。
- 移除提交后的阶段复核入口及提醒，审核集中在工作区完成。

## 历史工具与操作保护

- 二分查找、整理提交收进「提交历史 → 更多工具」，菜单显示用途说明。
- 修正「暂存 / 贮藏」提示。二分查找的启动、标记和还原会检查工作区及暂存区，保护测试过程中产生的修改。
- 正在进行的二分会话不能被新会话替换；分叉历史的错误端点会在检出前拒绝。
- 相邻提交可直接显示定位结果；执行中禁用关闭，支持关闭后重新打开继续会话。
