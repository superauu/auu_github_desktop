Ice Rounded was drawn for AuuGit. All other artwork retains its upstream license.

The Phinger, WhiteSur and Vimix SVG assets remain editable SVGs. Bibata SVGs use the official Ice, Classic and Amber color replacements from render.json, with display dimensions set to 32px. Nordzy Windows CUR and GoogleDot PNG assets were converted to 32px PNGs with their original colors and alpha transparency. Editable originals and license texts are provided under sources/.

Only the arrow and link-pointer roles are customized. Text editing, resizing, busy and unavailable roles use native system cursors.
